# 📓 나의 기록장

운동·바이올린, 경제 공부·투자, 그림 연습을 남기는 **나 혼자 쓰는 기록 사이트**예요.
설치할 것도, 로그인도, 인터넷 연결도 필요 없어요.

## 실행 방법

1. 이 폴더에서 **`index.html`** 파일을 **더블클릭**하세요.
2. 크롬, 엣지, 사파리 같은 브라우저가 열리면서 기록장이 나타나요. 끝!

> 처음 열면 **예시 기록**이 들어 있어요. 어떤 모습인지 보여 주려는 것이라 언제든 지울 수 있어요.

## 기본 사용법

| 하고 싶은 일 | 방법 |
| --- | --- |
| 기록 추가 | 각 메뉴의 **＋ 버튼** → 칸을 채우고 **저장** (`*` 표시는 꼭 써야 하는 칸) |
| 기록 고치기 | 기록 카드의 **수정** 버튼 |
| 기록 지우기 | 기록 카드의 **삭제** 버튼 (한 번 더 물어봐요) |
| 그림 넣기 | 그림 기록 추가 → **그림 이미지**에서 파일 선택 (큰 사진은 자동으로 줄여서 저장해요) |
| 그림 비교하기 | 그림 메뉴의 **↔ 나란히 비교**, 또는 카드의 **이전 작업과 비교** |
| 주간 요약 보기 | 운동·바이올린 메뉴 위쪽. **◀ 이전 주 / 다음 주 ▶** 로 이동 (월요일~일요일 기준) |
| 투자 복기하기 | 투자 기록 카드의 **복기 쓰기** → "나중에 돌아본 결과" 칸 작성 |

투자 기록은 **기록과 복기만** 할 수 있어요. 매매를 추천하거나 주문하는 기능, 계좌 연결은 없어요.

## 예시 기록 지우기

오른쪽 위 **⚙ 백업·설정** → **예시 기록만 지우기**.
내가 쓴 기록은 그대로 남아요. (예시를 직접 수정하면 내 기록이 되어 남아요.)
한 번 지우면 예시는 다시 생기지 않아요.

## ⚠️ 꼭 알아 두세요: 기록은 이 브라우저 안에 저장돼요

- 새로고침하거나 브라우저를 껐다 켜도 기록은 남아 있어요.
- 하지만 **"방문 기록·사이트 데이터 삭제"** 를 하거나 **다른 브라우저·다른 컴퓨터**로 열면 보이지 않아요.
- 그래서 가끔 **⚙ 백업·설정 → 백업 파일 내려받기**로 파일을 저장해 두세요. (그림까지 다 들어 있어요.)
- 백업 파일은 같은 화면의 **백업 파일 불러오기**로 되살릴 수 있어요.
- 항상 같은 브라우저(예: 크롬)로 여는 것을 권해요.

## ✨ 새로 생긴 기능

### 1. 백업 알림
- 마지막으로 **백업 파일을 내려받은 날짜**를 기억해요. **⚙ 백업·설정** 화면에서도 볼 수 있어요.
- 백업한 지 **14일이 지났거나 한 번도 안 했으면**, 화면 위쪽에 빨간 안내 줄이 나타나요.
  예: "마지막 백업 후 16일이 지났어요 [지금 백업] [나중에]"
- **[지금 백업]** 을 누르면 바로 백업 파일이 내려받아지고 안내 줄이 사라져요.
- **[나중에]** 를 누르면 **3일 동안** 안내 줄이 보이지 않아요.
- 기록이 하나도 없을 때는 안내 줄을 띄우지 않아요.
- 몇 일마다 알릴지는 `app.js`의 `BACKUP_REMIND_DAYS`(14), 미루는 기간은 `BACKUP_SNOOZE_DAYS`(3)에서 바꿀 수 있어요.

### 2. 빠른 기록 (⚡ 보라색 버튼)
운동·바이올린 / 경제 공부·투자 / 그림 메뉴마다 **⚡ 빠른 기록** 버튼이 있어요.
날짜(오늘로 미리 채워져 있어요), 종류, 시간(분), 한 줄 메모만 적으면 끝나요.

| 메뉴 | 종류 | 한 줄 메모가 들어가는 곳 |
| --- | --- | --- |
| 운동·바이올린 | 요가 / 슬로조깅 / 바이올린 연습 | 운동은 "메모", 바이올린은 "연습한 부분" |
| 경제 공부·투자 | 공부 메모 / 투자 기록 | 공부는 "주제", 투자는 "관심 자산·종목" (투자 기록은 시간 칸이 없어요) |
| 그림 | 연필·드로잉 / 색연필 / 수채·물감 / 디지털 / 기타 | "연습 주제" (종류는 "사용한 도구"로 저장돼요) |

- 빠른 기록으로 만든 카드에는 **보라색 "간단 기록"** 표시가 붙어요.
- 나중에 카드의 **수정** 버튼으로 나머지 칸을 채울 수 있어요. 꼭 써야 하는 칸까지 채워서 저장하면 "간단 기록" 표시가 사라져요.
  (예: 곡 이름 없이 빠르게 남긴 바이올린 연습은 곡 이름을 적을 때까지 표시가 남아 있어요.)
- 휴대폰 화면에서는 버튼과 입력 칸이 손가락으로 누르기 편하게 더 크게 보여요.
- 종류 목록은 `app.js` 맨 위의 `QUICK` 부분에서 바꿀 수 있어요.

### 3. 바이올린 레슨 노트와 곡별 템포
- **레슨 기록**: 바이올린 기록을 추가할 때 **종류**를 "레슨"으로 고르면 **선생님 피드백**과 **다음 레슨까지 과제** 칸만 나타나요.
  과제는 한 줄에 하나씩 적으면 체크박스 목록이 돼요.
- **과제 확인**: 운동·바이올린 메뉴 **맨 위**에 가장 최근 레슨의 과제가 나와요. 그 자리에서 바로 체크하면 저장돼요.
  (레슨 카드 안에서도 체크할 수 있어요. 수정에서 과제를 더 적어도 이미 체크한 것은 그대로예요.)
- **템포(BPM)**: 연습 기록에 **곡 이름**과 **템포(BPM)** 칸이 있어요. (예전의 "곡" 칸이 "곡 이름"이 되었어요. 기존 기록은 그대로 이어져요.)
  곡 이름 칸을 누르면 **전에 쓴 곡 이름이 자동완성**으로 나타나요.
- **템포 그래프**: 기록 카드나 주간 요약에서 **곡 이름(보라색 밑줄)을 누르면** 날짜별 템포 변화를 선 그래프로 보여줘요.
  같은 날 여러 번 연습했으면 마지막 템포를 써요. 템포가 적힌 기록이 두 개 이상이어야 선으로 이어져요.
- 주간 요약의 바이올린 연습 시간과 연습한 날은 **연습 기록만** 세고, 레슨은 "레슨 N회"로 따로 보여줘요.

### 예전 기록과 백업 파일은 그대로 써요
- 예전에 만든 기록은 그대로 보여요. 종류 칸이 없던 바이올린 기록은 "연습"으로 취급해요.
- 예전에 받은 백업 파일도 그대로 불러올 수 있어요. 백업 파일 형식은 바뀌지 않았어요.

## 글자(항목 이름, 선택지) 바꾸기

`app.js` 파일을 메모장으로 열면 맨 위에 **"1. 설정"** 이 있어요. 여기서 고칠 수 있어요.

```js
{ key: 'kind', label: '종류', type: 'select', options: ['요가', '슬로조깅'], required: true },
```

- **운동 종류 추가**: `options: ['요가', '슬로조깅', '걷기']` 처럼 따옴표로 감싸 쉼표로 이어 붙이기
- **항목 이름 바꾸기**: `label:` 뒤의 글자만 바꾸기
- 따옴표(`'`)와 쉼표(`,`)는 지우지 마세요. 잘못되면 되돌려 놓으면 돼요.
- 색깔은 `style.css` 맨 위 `:root { ... }` 의 색 값을 바꾸면 돼요.
- 파일을 고친 뒤에는 브라우저에서 새로고침(F5)하면 반영돼요. 기존 기록은 그대로예요.

- `app.js` : 동작과 항목 설정
