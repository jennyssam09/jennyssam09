# 📓 나의 기록장

운동 · 바이올린 · 그림 · 경제 루틴 · 영어를 남기는 **나 혼자 쓰는 기록 사이트**예요.
설치할 것도, 로그인도, 인터넷 연결도 필요 없어요. (**☁ 구글 드라이브 동기화**는 원할 때만 켜는 선택 기능이에요.)

## 실행 방법

1. 이 폴더에서 **`index.html`** 파일을 **더블클릭**하세요.
2. 크롬, 엣지, 사파리 같은 브라우저가 열리면서 기록장이 나타나요. 끝!

> 처음 열면 **예시 기록**이 들어 있어요. 어떤 모습인지 보여 주려는 것이라 언제든 지울 수 있어요.

위쪽 메뉴 순서는 **✏️ 오늘 · 🧘 운동 · 🎻 바이올린 · 🎨 그림 · 📚 경제 루틴 · 📰 영어 · 📅 캘린더** 예요.

## 기본 사용법

| 하고 싶은 일 | 방법 |
| --- | --- |
| 기록 추가 | 각 메뉴의 **＋ 버튼** → 칸을 채우고 **저장** (`*` 표시는 꼭 써야 하는 칸) |
| 기록 고치기 | 기록 카드의 **수정** 버튼 |
| 기록 지우기 | 기록 카드의 **삭제** 버튼 (한 번 더 물어봐요) |

| 경제 루틴 체크 | **📚 경제 루틴** 메뉴에서 체크만 하면 바로 저장돼요 (오늘 탭의 📚 버튼에서도 돼요) |
| 영어 기사 남기기 | **📰 영어** 메뉴의 **＋ 이번 주 기사 추가** → 링크·제목·세 줄 요약 |
| 바이올린 교재 고르기·관리 | 바이올린 기록 창의 **교재** 칩 · 옆의 **⚙︎ 교재 관리** |
| 그림 넣기 | 그림 기록 추가 → **내 그림** (모작이면 **원본 이미지**도) — 큰 사진은 자동으로 줄여서 저장해요 |
| 워치 캡처 넣기 | 🧘 운동 화면에 캡처를 **끌어다 놓기 / Ctrl+V**, 또는 운동 기록의 **워치 캡처** 칸 |
| **클로드에게 물어보기** | **✏️ 오늘** 탭 아래 **🤖 클로드에게 보내기**, 또는 카드의 **🤖** → 아래 「🤖 클로드 피드백 쓰는 법」 |
| 받은 피드백 다시 보기 | 각 메뉴의 **💬 피드백** 칩 (전체 / 해볼 것만) |
| 그림 비교하기 | 그림 메뉴의 **↔ 나란히 비교**, 또는 카드의 **이전 작업과 비교** |
| 쉰 날 남기기 | 오늘 탭의 **😴 오늘은 쉼**, 또는 캘린더 날짜 창의 **😴 이 날은 쉼** |
| 한 달 돌아보기 | 📅 캘린더 아래 **📖 이번 달 돌아보기** |
| 바이올린 녹음 붙이기 | 곡 이름을 눌러 **곡 노트**를 열고 **🎙 녹음 올리기**에 파일을 끌어다 놓기 |
| 도장 모아 보기 | 📅 캘린더 아래 **🎴 도장 모음판** |
| 연습 중인 곡·마무리한 곡 보기 | 🎻 바이올린 화면의 **📚 레퍼토리 책장** 칩 |
| 다른 기기와 같은 기록 보기 | 배포된 주소에서 위쪽 **☁ 칩** → 로그인 → 아래 「☁ 구글 드라이브 동기화」 |
| 입력 창 저장·닫기 | **Cmd+Enter** 저장 · **Esc** 닫기 |

## 예시 기록 지우기

오른쪽 위 **⚙ 백업·설정** → **예시 기록만 지우기**.
내가 쓴 기록은 그대로 남아요. (예시를 직접 수정하면 내 기록이 되어 남아요.)
한 번 지우면 예시는 다시 생기지 않아요.

## ⚠️ 꼭 알아 두세요: 기록은 이 브라우저 안에 저장돼요

> 💡 아래의 **자동 저장**(💾)을 켜 두면 안심이에요. 아래 "자동 저장" 설명을 꼭 읽어 보세요.

- 새로고침하거나 브라우저를 껐다 켜도 기록은 남아 있어요.
- 하지만 **"방문 기록·사이트 데이터 삭제"** 를 하거나 **다른 브라우저·다른 컴퓨터**로 열면 보이지 않아요.
- 그래서 가끔 **⚙ 백업·설정 → 백업 파일 내려받기**로 파일을 저장해 두세요. (그림까지 다 들어 있어요. 이번에 새로 생긴 **받은 피드백·내 정보·요청 문구·교재 목록**도 함께 들어가요.)
- 백업 파일은 같은 화면의 **백업 파일 불러오기**로 되살릴 수 있어요.
- 항상 같은 브라우저(예: 크롬)로 여는 것을 권해요.
- 다른 기기에서도 보고 싶다면 **☁ 구글 드라이브 동기화**를 켜세요. (아래 「☁ 구글 드라이브 동기화」)
- 🎙 **녹음은 곡마다 첫 녹음만 백업돼요.** 나머지 녹음은 이 브라우저에만 저장돼서, 사이트 데이터를 지우면 사라져요. (아래 ✨ 이전에 생긴 기능 → 🎙 참고)

## ☁ 구글 드라이브 동기화 (선택)

아이맥과 갤럭시 Z 폴드가 **같은 기록**을 보게 해 줘요. 켜지 않아도 지금까지처럼 **`index.html`을 더블클릭해서 쓰는 방식은 그대로** 돼요. (동기화는 **배포된 주소**에서만 쓸 수 있어요.)

- 내 **구글 드라이브의 "나의 기록장 (동기화)" 폴더** 하나만 써요. 내 다른 파일은 볼 수 없어요. (권한은 `drive.file` 하나예요.)
- 서버도, 비밀번호도, 비밀 키도 없어요. 로그인 정보(토큰)는 **저장하지 않고** 창을 닫으면 사라져요.
- **기록 글은 `journal.json` 하나**, **그림·워치 캡처는 한 장에 파일 하나**로 올라가요.
- 🎙 **녹음은 이 기기에만 저장돼요.** Drive로 올라가지 않아요. (백업 파일의 "곡마다 첫 녹음"과는 별개예요.)

### 1단계. 배포하기 (GitHub Pages)

> ⚠️ **먼저 저장소 이름부터 바꿔 주세요.**
> 지금 저장소 이름이 내 GitHub 아이디와 같아서(`jennyssam09/jennyssam09`), GitHub가 이 저장소를 **"프로필 저장소"**로 보고 **이 README를 내 GitHub 프로필 첫 화면에 보여 줘요.** 이름을 `my-journal` 로 바꾸면 그런 일이 없어요.

**① 저장소 이름 바꾸기** (웹사이트에서)
1. 저장소 페이지 → 위쪽 **Settings**(설정) → 첫 화면 **General** 의 **Repository name** 칸에 `my-journal` 을 적고 **Rename**(이름 변경)을 눌러요.
2. 예전 주소로 들어가도 GitHub가 새 주소로 넘겨 주지만, 아래처럼 **내 컴퓨터의 git 주소도 바꿔 두는 걸 권해요.**

**② 내 컴퓨터의 git 원격 주소 바꾸기** (터미널)
```
cd 나의기록장폴더            # index.html이 들어 있는 폴더
git remote -v               # 지금 주소 확인 (jennyssam09/jennyssam09 로 보이면 바꿔야 해요)
git remote set-url origin https://github.com/jennyssam09/my-journal.git
git remote -v               # my-journal 로 바뀐 걸 확인
git fetch                   # 잘 연결됐는지 확인 (오류가 없으면 끝)
```
(ssh 주소를 쓰고 있다면 `git@github.com:jennyssam09/my-journal.git` 로 바꿔요. 다른 사람 아이디라면 `jennyssam09` 자리를 내 아이디로 읽어 주세요.)

**③ 저장소를 공개(Public)로** — 무료 GitHub Pages는 공개 저장소에서만 돼요.
Settings → 맨 아래 **Danger Zone** → **Change repository visibility** → **Public**.
공개해도 **내 기록은 보이지 않아요.** (기록은 내 Drive와 내 브라우저에만 있어요.) 앱 코드와 예시 문구만 누구나 볼 수 있어요.

**④ 기본 브랜치를 `main` 으로 바꾸고, 이 작업을 합치기**
GitHub Pages는 `main` 을 기준으로 올리는 게 편한데, **이 저장소의 기본 브랜치 이름은 지금 `main` 이 아니라 `claude/clever-edison-2uvnkz` 예요.** 먼저 이름을 바꿔 주세요.
1. 저장소 **Settings** → **General**(또는 **Branches**) → **Default branch** 옆의 ✏️ 연필(**Rename branch**) → `main` 으로 바꾸고 **Rename**. (열려 있는 PR은 새 이름을 자동으로 따라가요.)
2. **Pull requests** 탭에서 이 작업의 PR(**#2**)을 열어 **Merge pull request** 를 눌러요. → `main` 에 이 앱이 통째로 들어가요.
3. 예전 PR **#1** ("Add quick daily logging…")은 그 내용이 이미 이 앱에 합쳐져 있어서 **Close**(닫기)만 해 주세요. (합치면 충돌이 나요.)
4. 내 컴퓨터에서는 `git fetch --prune` 다음 `git checkout main` 으로 새 이름의 브랜치를 받아 써요.

**⑤ GitHub Pages 켜기**
1. Settings → 왼쪽 **Pages**
2. **Source**: `Deploy from a branch` / **Branch**: `main` (④에서 바꾼 이름) , 폴더 `/ (root)` → **Save**
3. 1~2분 기다리면 위쪽에 주소가 나와요. 이 앱의 주소는 **`https://jennyssam09.github.io/my-journal/`** 처럼 생겼어요. (`jennyssam09` 자리는 내 아이디)
4. 그 주소를 열어 기록장이 보이면 배포 성공이에요. (처음엔 **기록이 비어 있어요** — 아래 2단계로 옮겨요.)

### 2단계. 예전 기록을 배포 주소로 옮기기

파일(`index.html`)로 열어 쓰던 기록은 **배포된 주소의 기록과 저장 공간이 서로 달라요.** 백업 파일로 옮겨요.
1. **예전 방식**(index.html 더블클릭)으로 열어서 **⚙ 백업·설정 → 백업 파일 내려받기**
2. **배포된 주소**를 열어서 **⚙ 백업·설정 → 백업 파일 불러오기** → 방금 받은 파일 고르기
3. 위쪽 **☁ 로그인** → 구글 로그인 → 처음 연결이라 Drive가 비어 있으면 **이 기기 기록이 자동으로 올라가요.**
4. 다른 기기(폴드)에서는 배포된 주소를 열고 ☁ 로그인만 하면 **Drive의 기록을 받아 와요.** (그 기기에 기록이 없으면 물어보지도 않아요.)

### 3단계. 구글 설정 (클라이언트 ID 만들기)

> 콘솔 화면 이름은 구글이 자주 바꿔요. 이름이 조금 달라도 비슷한 메뉴를 찾아 주세요. 지금은 **"Google Auth Platform"** 이라는 이름이에요.

1. https://console.cloud.google.com 에 **내 구글 계정**으로 들어가서 **프로젝트 만들기** (이름 예: `my-journal`)
2. **API 및 서비스 → 라이브러리 → "Google Drive API" → 사용**
3. **Google Auth Platform → 시작하기**: 앱 이름(예: 나의 기록장), 지원 이메일, 대상 **외부(External)**, 연락처 이메일을 넣어요.
4. **데이터 액세스(범위)** 에는 **`.../auth/drive.file` 하나만** 추가해요. (다른 것은 넣지 마세요.)
5. **대상(Audience)**: 처음에는 **테스트** 상태로 두고, **테스트 사용자에 내 Gmail을 추가**해요. (폴드에서 쓰는 계정도 같은 계정이면 됩니다.)
6. **클라이언트 → 클라이언트 만들기 → 웹 애플리케이션**
   - **승인된 JavaScript 원본**: `https://jennyssam09.github.io` ← **주소 맨 뒤 `/` 와 `/my-journal/` 같은 경로는 붙이지 마세요.**
   - (컴퓨터에서 시험하려면 하나 더) `http://localhost:8000`
   - **승인된 리디렉션 URI 는 비워 둬요.** (이 앱이 쓰는 방식은 필요 없어요.)
7. 만들어지면 나오는 **클라이언트 ID** (`…apps.googleusercontent.com`)를 복사해서 **`sync-config.js`** 를 열어 붙여 넣어요.
   ```js
   window.SYNC_CONFIG = {
     clientId: '여기에-클라이언트-ID.apps.googleusercontent.com',
     deployUrl: 'https://jennyssam09.github.io/my-journal/',
     folderName: '나의 기록장 (동기화)',
   };
   ```
   - 클라이언트 ID는 **비밀이 아니라서** 저장소에 올려도 돼요.
   - **"클라이언트 보안 비밀번호(secret)"는 어디에도 붙여 넣지 마세요.** 이 앱은 필요 없어요.
8. 고친 `sync-config.js` 를 저장소에 올려요 (`git add sync-config.js && git commit -m "클라이언트 ID" && git push`, 또는 GitHub 웹에서 파일을 열어 ✏️ 로 고치기). 1~2분 뒤 배포 주소에 반영돼요.
9. 설정이 반영되기까지 **몇 분에서 몇 시간** 걸릴 수 있어요. 로그인 창에 오류가 나면 잠깐 기다렸다가 다시 해 보세요.

**테스트 상태로 시작해요.** 이 상태에서는 **테스트 사용자로 넣은 계정만** 로그인할 수 있고, 구글이 **약 7일마다 로그인 허용을 다시 물어볼 수 있어요.** (그럴 땐 위쪽 칩이 "다시 연결"로 바뀌니 한 번 누르면 돼요.)

**프로덕션(게시)으로 바꾸는 방법** — 7일마다 다시 묻는 일을 없애고 싶을 때
1. Google Auth Platform → **대상(Audience)** → **앱 게시(Publish app)** → 확인 → 상태가 **"프로덕션"** 으로 바뀌어요.
2. 이 앱이 쓰는 `drive.file` 은 **민감하지 않은 범위라서 따로 심사 없이 게시할 수 있는 것으로 알고 있어요.** (구글 정책은 바뀔 수 있으니 콘솔에 나오는 안내를 꼭 확인하세요.)
3. 게시한 뒤에는 테스트 사용자 목록이 필요 없어요. 처음 로그인할 때 "Google에서 확인하지 않은 앱" 안내가 나오면 **고급 → 나의 기록장(안전하지 않음)으로 이동**을 누르면 돼요. (내가 만든 앱이라서요.)

**언제 동기화하나요?** 사이트를 열 때 · 로그인할 때 · 기록을 저장하고 5초쯤 뒤 · 다른 창에 갔다가 돌아왔을 때 · 인터넷이 다시 연결될 때 · 상세 창의 **지금 동기화**를 눌렀을 때.

**처음 로그인** — 이 기기에 이미 기록이 있으면
1. 먼저 **이 기기 백업 파일이 자동으로 내려받아져요** (`my-journal-backup-before-sync-날짜.json`).
2. Drive가 비어 있으면 이 기기 기록을 올려요.
3. Drive에도 기록이 있으면 "이 기기 N개 · Drive M개"를 보여 주고 물어봐요.
   - **합치기 (추천)**: 양쪽을 모두 남겨요. 같은 기록이 다르게 적혀 있을 때만 어느 쪽을 남길지 물어요.
   - **이 기기 → Drive 로 덮어쓰기**: Drive에 있던 기록이 이 기기 기록으로 바뀌어요. (Drive 폴더의 "버전 관리"에서 한동안 되돌릴 수 있어요.)
   - **Drive → 이 기기 로 덮어쓰기**: 이 기기 기록이 Drive 기록으로 바뀌어요. (방금 받은 백업 파일이 있어요.)

**충돌이 나면** — 창에 **왼쪽 "이 기기" | 오른쪽 "Drive"** 로 **다른 칸만** 나란히 보여요.
- **이 기기 것으로 / Drive 것으로 / 둘 다 남기기** (Drive 것을 "(Drive에서 온 사본)"이라는 새 기록으로 붙여요)
- 한 기기에서 **지우고** 다른 기기에서 **고친** 경우도 충돌이에요. (삭제 유지하기 / 되살리기)
- 고르기 전까지 **이 기기의 기록은 그대로**예요. 다른 기록의 동기화는 계속돼요.
- 교재 목록·"내 정보·요청 문구" 같은 **설정은 충돌 창 없이 더 나중에 바꾼 것**이 남아요.

**오랜만이에요 (60일)** — 지운 기록의 흔적은 60일 뒤에 정리돼요. 그래서 **60일 넘게 동기화하지 않은 기기**는 합치기 전에 먼저 물어봐요: **"Drive 기준으로 새로 받기 (추천)"** 또는 **"그래도 합치기"**. 새로 받기 전에는 **이 기기 백업 파일이 자동으로 내려받아져요.**

**로그아웃** — 구글 연결을 끊고(토큰 취소) 메모리의 로그인 정보를 지워요. **이 기기의 기록은 그대로 남겨요.** "이 기기의 기록도 지우기"는 따로 물어보고, 지우기 전에 백업 파일을 자동으로 내려받아요. (녹음은 지우지 않아요.) 같은 계정으로 다시 로그인하면 이어서 동기화돼요.

> **모든 기록 지우기**(⚙ 백업·설정)는 동기화가 켜져 있으면 **Drive와 다른 기기에서도 지워져요.** 이 기기에서만 지우려면 먼저 로그아웃하세요. (그래서 확인 창에 그렇게 적혀 있어요.)

### 알아 둘 것

- **Drive 폴더 안의 파일은 지우거나 옮기거나 이름을 바꾸지 마세요.** (`journal.json`, `img-…jpg`) 그러면 앱이 "Drive 파일이 없어요"라고 알려 줘요. 이 기기의 기록은 그대로라서 다시 만들 수 있어요.
- **구글 클라이언트 ID(구글 프로젝트)를 새로 만들면** 예전 ID로 만든 Drive 파일이 새 ID에서는 보이지 않아요. (`drive.file` 은 "이 앱(ID)이 만든 파일"만 보여요.) 한 번 정한 ID는 계속 쓰세요.
- **같은 `아이디.github.io` 주소를 쓰는 다른 사이트와 저장소가 섞이지 않게**, 이 앱이 브라우저에 만드는 저장 이름에는 모두 `my-journal` 이 들어가요. (IndexedDB `my-journal`·`my-journal-audio`, localStorage `my-journal.records`) 다만 같은 주소의 다른 사이트는 원래 서로의 저장소를 읽을 수 있으니, 같은 주소에 믿을 수 없는 페이지는 올리지 마세요.
- 지운 기록은 **"삭제 표시"** 로 60일 동안 남아요. 화면과 백업 파일에는 나타나지 않고, 60일 뒤 정리돼요.
- 큰 그림이 많으면 **처음 동기화가 몇 분** 걸릴 수 있어요. 이후에는 바뀐 그림만 올라가요. 그림을 바꾸면 예전 그림 파일은 Drive **휴지통**으로 가요.
- 브라우저 창(탭)을 여러 개 열어도 한 번에 한 창만 동기화해요.
- 백업 파일의 모양은 그대로예요. 동기화 정보와 삭제 표시는 백업 파일에 들어가지 않아요.

### 개인정보와 접근 끊기

- 기록은 **내 브라우저와 내 구글 드라이브**에만 있어요. 이 앱의 서버는 없어서, 개발자나 제3자에게 기록이 가지 않아요.
- 구글 로그인 도구(`accounts.google.com`)는 **동기화를 쓸 때만** 불러와요. `file://` 로 열었거나 로그인하지 않았으면 구글에는 아무 요청도 가지 않아요.
- **접근 끊기**: 앱의 ☁ → **로그아웃** (토큰 취소) 또는 https://myaccount.google.com/permissions → "나의 기록장" → **액세스 삭제**. Drive의 폴더는 직접 지우면 돼요.

### ✅ 직접 확인해 보세요 (진짜 구글 계정으로, 순서대로)

제가 있는 환경에서는 진짜 구글 계정으로 로그인할 수 없어서, **가짜 Drive·가짜 로그인**으로만 시험했어요. 아래는 직접 해 보셔야 하는 것이에요.
1. 저장소 이름을 `my-journal` 로 바꾸고 git 원격 주소를 바꿔요. (1단계 ①②)
2. 저장소를 Public 으로 바꾸고, 기본 브랜치 이름을 `main` 으로 바꾸고, PR #2를 합치고, Pages를 켜요. → 배포 주소가 열리는지 (1단계 ③④⑤)
3. 구글 콘솔에서 3단계 1~7번을 하고, 클라이언트 ID를 `sync-config.js` 에 넣어 올려요. (8번)
4. **컴퓨터(아이맥)** 에서 배포 주소 → ☁ 로그인 → 실제 구글 동의 화면·로그인 팝업이 뜨는지 → "동기화됨"이 되는지 → Drive에 "나의 기록장 (동기화)" 폴더와 `journal.json` 이 생겼는지
5. 예전 파일 버전의 백업을 불러와서(2단계) 그림이 있는 기록도 올라가는지 (Drive 폴더에 `img-…jpg` 가 생기는지)
6. **폴드**에서 배포 주소 → ☁ 로그인 → 아이맥의 기록이 내려오는지, 그림도 보이는지
7. 아이맥에서 기록을 고치고 → 폴드에서 앱으로 돌아왔을 때 반영되는지 (반대로도)
8. 두 기기에서 **같은 기록**을 서로 다르게 고쳐서 **충돌 창**이 뜨는지, 세 가지 선택이 되는지
9. **1시간 넘게** 열어 두었다가 기록을 고쳐 보기: 조용히 이어지는지, 폰에서 막히면 "다시 연결" 칩을 **한 번** 눌러 바로 로그인 창이 뜨고 쌓인 변경이 올라가는지
10. 비행기 모드에서 기록을 남기고 → 켜서 자동으로 올라가는지
11. 폴드를 **접고 펼치면서** 입력 창에 쓰던 글이 그대로인지, 키보드가 입력 칸을 가리지 않는지, 버튼이 누르기 편한지
12. ☁ → 로그아웃 → https://myaccount.google.com/permissions 에서 "나의 기록장"이 사라지는지(취소되는지)

### 🛡 0. 업데이트 전에 자동으로 백업해요 (그리고 물어봐요)
이번 업데이트에서는 **없어진 기능의 예전 데이터**가 있어서, 정리하기 **직전에** 백업부터 해요.
- 처음 열었을 때 정리할 것이 **있으면**: ① 먼저 **전체 백업 파일이 다운로드 폴더에 저장돼요.** 파일 이름은 `my-journal-backup-before-update-20260930.json` (날짜는 그날 날짜) 처럼 생겼어요. ② 그다음 **"업데이트 전에 백업을 저장했어요. 예전 투자·경제 메모와 일부 칩 값을 정리합니다"** 확인 창이 떠요. **확인을 눌러야만** 정리가 시작돼요. **취소하면 아무것도 지우지 않아요.** (다음에 열 때 다시 물어봐요.)
- 정리할 것이 **없으면** 아무 창도 뜨지 않고 조용히 끝나요.
- **정리되는 것은 딱 이것뿐**이에요:
  - 📚 **경제 공부 메모**와 📊 **투자 기록** (경제 공부·투자 메뉴가 없어졌어요. 경제 루틴으로 바뀌었어요)
  - 🎻 바이올린 예전 칸: **오늘 한 것(예전 칩)**, **집중한 점**
  - 🎨 그림 예전 칸: **종류(모작·창작·연습)**, **연습 영역**, **사용한 도구**, **새로 시도한 점**, **어려웠던 점**
  - 그 밖의 칸(곡 이름, 잘 된 것, 메모, 그림, 날짜 등)은 **하나도 건드리지 않아요.**
- **예전 백업 파일을 불러올 때도** 같은 규칙이에요. 불러오는 기록에서 위의 옛 종류·칸은 들어오지 않아요. (불러오기 창에는 실제로 들어오는 개수가 나와요.)
- 혹시 잘못됐다면 다운로드 폴더의 `my-journal-backup-before-update-…json`을 **⚙ 백업·설정 → 백업 파일 불러오기**로 열면 돼요. (그 파일에는 정리 전 상태가 그대로 들어 있어요. 단, 이 새 버전은 없어진 종류를 다시 화면에 보여 주지는 않아요.)

### 🎻 1. 바이올린이 따로 메뉴가 됐어요
- 예전의 "운동·바이올린" 메뉴가 **🧘 운동**과 **🎻 바이올린** 두 메뉴로 나뉘었어요. (레슨 과제 패널·레퍼토리 책장·주간 요약은 🎻 바이올린 쪽에 있어요.)
- **입력 창 (연습)** 기본 층: 곡 이름 → **오늘 한 것**(활 / 기본기 / 곡 — 여러 개) → **교재**(칩) → 연습량 → 기분.
  - **기본기**는 스케일 · 에튀드 · 개방현 · 포지션 이동을 모두 포함해요.
  - 예전의 "오늘 한 것", "집중한 점" 칸은 없어졌어요. (0단계 참고)
- **✍ 더 적기**: 오늘 잘 된 것 하나 → 다음에 해볼 것 하나 → 레슨 때 물어볼 것 → **교재 몇 번·몇 쪽** → 템포 → 연습한 부분 → 🎙 녹음.
- **⚙︎ 교재 관리** (교재 칩 옆 버튼): 작은 창이 위에 열려요. **교재 추가 · ▲▼ 순서 바꾸기 · 숨기기 · 숨긴 교재 다시 보이기**를 할 수 있어요. 처음 목록은 `스즈키 4권` 하나예요. **숨겨도 지우는 게 아니에요** — 예전 기록에는 그 교재 이름이 그대로 보여요. 목록은 백업에 함께 들어가요. `Esc`는 작은 창만 닫아요.
- 교재를 고르면 **곡 이름 자동완성**에서 그 교재로 연습한 곡이 먼저 나와요.

### 🎨 2. 그림 기록이 "원본 | 내 그림" 중심이 됐어요
- 입력 창 순서: **내 그림 → 원본 이미지(선택) → 원작자 → 그린 것 → 단계 → 연습량·기분**. ✍ 더 적기의 첫 칸은 **마음에 드는 곳 하나**, 그다음 **원본과 다른 점 · 내 그림에 가져갈 것 하나 · 다음엔 이걸 바꿔 그려 보기(표정·머리·옷·각도) · 바꿔 그릴 것 한 줄 · 참고한 강의·영상 · 링크**.
- **단계**는 **그대로 모작 / 조금 바꿔 그리기 / 창작** 중에서 골라요. (조금 바꿔 그리기 = 원본에서 표정·머리·옷·각도 중 하나만 바꿔 보기)
- 카드는 원본이 있으면 **"원본 | 내 그림"이 좌우로 나란히** 나와요. 누르면 크게 볼 수 있어요.
- 그림 메뉴의 칩: **📖 기록장 · 🖼 그림 연대기 · 🧰 가져갈 것 모음 · ↔ 나란히 비교 · 💬 피드백**
  - **🖼 그림 연대기**: 모든 그림을 **날짜순**으로 큰 그림으로 쭉 이어 보여요. 원본이 있으면 작은 원본이 옆에 붙고, **단계만 작게** 표시돼요. (점수·순위는 없어요.)
  - **🧰 가져갈 것 모음**: "내 그림에 가져갈 것"만 최신순으로 모아요. **그림 보기**를 누르면 그 카드로 가요.
- 카드의 **🤖 클로드에게 보내기**는 글만 복사해요. **그림 이미지는 클로드 대화창에 직접 첨부**해 주세요. (복사할 때 그렇게 알려 줘요.)
- 예전의 그림 종류·연습 영역 필터, 📺 강의별 보기는 없어졌어요.

### ✅ 3. 📚 경제 루틴 (경제 공부·투자 메뉴가 바뀌었어요)
- **입력 창이 없어요. 체크만 해요.** 체크하는 순간 저장돼요 (저장 버튼 없음). 하루에 기록 하나가 만들어져요.
  - 🎧 **경제 팟캐스트 듣기**
  - 📮 **뉴스레터 읽기** — 옆에 **잘쓸레터 · 머니레터** 칩이 있어요. 칩을 누르면 읽은 것으로 표시되고, 뉴스레터 체크도 함께 켜져요. (체크를 풀면 칩 표시도 풀려요. 둘 다 골라도 돼요.)
- **오늘 한 줄**(선택): 입력을 멈추면 **저절로 저장**돼요. **태그**(금리 · 인플레이션 · 환율)를 눌러 붙이면, 그 태그가 붙은 **한 줄들이 아래에 모여** 열려요. **🔎 태그별로 모아 보기**로도 열어요.
- **이번 주(월~일)** 표: 항목마다 한 줄. 한 날은 ●, 안 한 날은 흐린 ·. **숫자·퍼센트는 없어요.** **지난 날짜의 점을 누르면 그날 체크를 켜고 끌 수** 있어요. (미래 날짜는 눌러지지 않아요.)
- 체크·칩·태그·한 줄이 **모두 비면 그날 기록은 저절로 사라져요.**
- 캘린더에는 ✅ 아이콘만 조용히 나타나고, **📖 돌아보기**에는 "🎧 N번 · 📮 N번"과 이번 달 오늘 한 줄이 나와요. (지난달과 비교하지 않아요.)
- 항목(팟캐스트·뉴스레터·칩)과 태그는 `app.js` 맨 위의 **`ECON_ROUTINES`**, **`ECON_TAGS`**에서 고칠 수 있어요.

### 📰 4. 영어 (새 메뉴)
일주일에 기사 하나를 읽고 **세 줄로 정리**해요.
- 기본 층: **기사 링크**(선택) · **기사 제목**(선택) · **요약 3줄**(선택 — 영어로 한두 줄만 써도 저장돼요). **✍ 더 적기**: **가져갈 표현(최대 3개)** · 내 생각 한 줄 · **말해 볼 주제로 표시**.
- 링크를 넣으면 카드에 **도메인**(예: theguardian.com)만 보이고, 누르면 새 창에서 열려요. **링크의 제목을 가져오는 등 밖으로 나가는 요청은 없어요.**
- 위쪽에 **이번 주 (9/28 ~ 10/4)** 표시가 있고, 이번 주 기록이 있으면 **✓** 가 붙어요. (연속 주 수·빠진 주는 세지 않아요.)
- 칩: **📰 기사 목록 · 💬 표현 모음**(가져갈 표현을 한곳에서. 누르면 그 기사로 가요) **· 🗣 말해 볼 주제 · 💬 피드백**
- 캘린더에는 📰 아이콘, 돌아보기에는 "기사 N개"와 가져갈 표현이 나와요.

- 연습량 버튼 이름: **살짝 / 적당히 / 듬뿍** (예전 값은 그대로 읽혀요)
- 캘린더 종류 버튼: 운동 · 바이올린 · 경제 루틴 · 영어 · 그림 · 쉼

### 🤖 클로드 피드백 쓰는 법
**기록 → 클로드에게 보내기 → 받은 피드백 저장 → 해볼 것 하나 → 다음 기록에 반영.** 이 한 바퀴가 목적이에요. (밖으로 나가는 요청은 없어요. **복사해서 붙여 넣는 방식**이에요.)

**① 기록을 글로 복사해요**
- ✏️ **오늘** 탭 아래 **🤖 클로드에게 보내기**에서 **기간**(오늘 / 이번 주 / 이번 달)과 **범위**(🎻 바이올린 / 🧘 운동 / 📚 경제 루틴 / 📰 영어)를 고르면, 보낼 글이 아래 칸에 **미리 보기**로 나와요. 미리 보기는 **직접 고쳐도 돼요.** 고친 글 그대로 복사돼요.
- **이번에 특히 물어볼 것**(선택, 한 줄)을 적으면 글에 들어가요. (저장하면 비워져요.)
- 기록이 없는 기간이면 "이 기간엔 기록이 없어요"가 뜨고 **복사하기**가 눌리지 않아요.
- **📋 복사하기**를 누르면 복사돼요. 카드마다 **🤖**(그림 카드는 🤖 클로드에게 보내기, 영어 카드는 🤖 첨삭 받기)를 누르면 **그 기록 하나만** 복사돼요.
- 복사되는 글의 순서는 이래요 (블록 사이는 빈 줄 하나):
  1. **내 정보** — 범위마다 한 번 써 두면 자동으로 맨 위에 붙어요
  2. **요청 문구** + 공통 문장 *"제안은 3개 이내로, 가장 중요한 것 하나를 맨 앞에 써 줘. 밤에 읽기 편하게 짧게."*
  3. **이번에 특히 물어볼 것** (적었을 때만)
  4. **지난번 받은 제안** — 같은 범위에서 최근에 받은 해볼 것 **최대 2개**, 각각 **(해봤음 / 아직)** 표시 + *"이번 기록에 반영됐는지도 봐 줘."*
  5. **기록 본문** — 채운 칸만 한 줄로 (날짜 · 곡 · 한 것 · 연습량 · 잘 된 것 …)
  6. **요약 한 줄** — 이번 주·이번 달일 때만 ("기록한 날 5일 · 살짝 1 · 적당히 3 · 듬뿍 1"처럼 개수만. 쉰 날·빈 날은 쓰지 않아요.)
- 클로드 대화창에 붙여 넣고 보내세요. 그림·워치 캡처는 글에 못 들어가니 **이미지를 직접 첨부**해요.

**② 받은 답변을 저장해요**
- 복사하면 아래 **💬 받은 피드백 붙여넣기**가 열려요. 클로드의 답변을 붙여 넣고, **이번에 해볼 것 하나**(한 줄)를 적고 **저장**을 눌러요. (답변만, 또는 해볼 것만 적어도 돼요.)
- 저장하면 작은 도장 알림이 나와요. 카드의 **🤖**로 보낸 답변은 그 카드 안에 열린 칸에 붙여 넣어요 → 카드에 **💬 1** 배지가 생기고, 누르면 펼쳐져요.
- 답변은 각 메뉴의 **💬 피드백** 칩에서 다시 볼 수 있어요. **[전체]**는 답변 전문(길면 3줄만 보이고 **더 보기**), **[해볼 것만]**은 해볼 것만 모아 **해봤음** 체크를 할 수 있어요. 각 항목은 **수정 / 삭제 / 기록 보기**가 있어요.

**③ 해볼 것 하나를 해요 — 다음 기록에 반영**
- 아직 안 해본 최근 해볼 것이 **입력 창 맨 위**에 **"💡 지난 피드백에서: …"** 로 나와요. **☐ 오늘 해봤음**에 체크하고 저장하면 그 기록에 "오늘 해본 것"으로 연결돼요. 안 뜨게 하려면 **✕ 숨기기** (지우는 건 아니고, 💬 피드백에는 그대로 있어요).
- 📚 경제 루틴 화면에는 체크 목록 아래 한 줄로, ✏️ 오늘 탭에는 **영역별로 최대 3줄**, 작게 나와요. 그 자리에서 바로 **해봤음** 체크가 돼요.
- 다음에 복사할 때 **"지난번 받은 제안: … (해봤음)"** 과 기록 줄의 **"해본 것(지난 제안): …"** 이 들어가서, 클로드가 **반영됐는지** 봐 줄 수 있어요.
- 📖 **이번 달 돌아보기**에 **"💬 이번 달 받은 해볼 것"** 이 나와요. **✓ 해봤음** 표시만 있고, 개수·퍼센트는 없어요.

**✎ 내 정보·요청 문구 바꾸는 법**
- 복사칸의 **✎ 내 정보·요청 문구** 버튼 → 창이 열려요. 위쪽 칩으로 범위(🎻 바이올린 · 🧘 운동 · 📚 경제 루틴 · 📰 영어 · 🎨 그림)를 바꿔 가며 **내 정보**와 **요청 문구**를 고쳐요. **기본값으로 되돌리기**로 그 칸만 처음 문구로 돌려요. 범위를 오가도 고치던 글은 남아 있고, **저장**을 눌러야 저장돼요. (**닫기**는 저장하지 않고 닫아요.)
- 처음 문구는 `app.js` 맨 위 **`CLAUDE_SCOPES`**에, 모든 요청 끝에 붙는 공통 문장은 **`CLAUDE_COMMON`**에 있어요. 화면에서 고친 값은 이 브라우저에 저장되고 **백업에도 들어가요.** (기본값과 같은 칸은 따로 저장하지 않아서, 나중에 기본 문구를 바꾸면 따라가요.)
- 카드의 🤖도 같은 설정을 써요.

> 참고: 예전의 "📋 클로드에게 보낼 요약 복사" 버튼과 `CLAUDE_REQUEST`는 이 복사칸으로 바뀌었어요. 운동 기록의 **"클로드 피드백"** 칸(붙여 두는 메모)은 그대로 있어요.

### 🔁 예전 기록과 백업 파일
- 백업 파일의 모양(`{ app: 'my-journal', version: 1, records: […] }`)은 **그대로**예요. 새 종류(`econRoutine`, `englishArticle`, `claudeFeedback`, `config`)와 새 칸(`checks`·`letters`·`note`·`tags`, `srcImage`·`stage`·`carry`, `books`·`whatDid`, `feedbackId` 등)이 **더해지기만** 해요.
- **예전에 받은 백업 파일도 그대로 불러와요.** (없어진 종류와 칸만 위 0단계 규칙대로 들어오지 않아요.)
- 예전에 "운동·바이올린" 메뉴에서 쓰던 기록은 새 두 메뉴에 그대로 나뉘어 보여요.

### 🎙 바이올린 녹음 붙이기
휴대폰으로 녹음한 파일을 곡에 붙여 두고, 나중에 **처음 녹음과 지금 녹음을 나란히** 들어 봐요. (직접 녹음하는 기능은 없어요.)

**올리는 곳 두 군데**
1. **곡 노트** (곡 이름의 보라색 밑줄을 누르면 열려요) → **🎙 녹음 올리기** 상자에 파일을 끌어다 놓거나 눌러서 고르기
2. **바이올린 연습 기록 창** → **✍ 더 적기 → 🎙 녹음** (그 기록의 곡에 붙어요. 곡 이름을 먼저 적어 주세요. 기록을 저장할 때 함께 붙어요)

**받는 파일과 제한**
- m4a · mp3 · wav · aac 같은 **오디오 파일**이에요. 오디오가 아닌 파일은 알아서 빼요.
- **한 파일에 5분(15MB)까지**예요. 넘으면 "5분 이내 녹음만 올릴 수 있어요. 녹음 앱 설정에서 음질을 '중간'으로 낮추면 파일이 작아져요"라고 알려 주고 받지 않아요.
- **녹음한 날**은 ① 파일 이름 속 날짜(예: `음성 260930_143012.m4a`, `KakaoTalk_20260930_…`, `2026-09-30`)를 먼저 찾고 ② 없으면 파일의 날짜로 미리 채워요. 올리기 전에 **고칠 수 있어요.** (카카오톡·구글 드라이브로 옮기면 파일 날짜가 옮긴 날로 바뀔 수 있어서 이름을 먼저 봐요.)
- 녹음마다 **한 줄 메모**(예: 2마디 음정 신경 씀)를 적을 수 있어요. 나중에 목록에서도 고칠 수 있어요.

**개수와 보관**
- **곡당 최대 5개**예요. 곡의 **첫 녹음은 "🌱 첫 녹음"**으로 표시되고 **자동으로 지워지지 않아요.**
- 6번째를 올리면 **"가장 오래된 녹음(첫 녹음 제외)을 지우고 올릴까요?"**라고 물어봐요. 취소하면 올리지 않아요.
- 녹음은 하나씩 **삭제**할 수 있어요 (확인 창이 떠요). 첫 녹음을 지워도 다음 녹음이 첫 녹음이 되지는 않아요. (표시는 비어 있어요)

**곡 노트에서 보기**
- **🎙 녹음** 영역: 날짜순 목록. 줄마다 재생 · 날짜 · 메모 · 삭제가 있어요.
- 녹음이 2개 이상이면 맨 위에 **"처음 vs 지금"** 칸: 첫 녹음(없으면 가장 오래된 것)과 가장 최근 녹음을 나란히 놓고 각각 들어요. **한쪽을 재생하면 다른 쪽은 자동으로 멈춰요.**
- 바이올린 연습 카드에 녹음이 붙어 있으면 작은 **🎙**이 보이고, 누르면 창을 열지 않고 바로 재생돼요. (다시 누르면 멈춰요)

**저장 방식 (알아 두면 좋아요)**
- 녹음 파일은 용량이 커서, 기록과 **다른 저장 칸**(브라우저의 IndexedDB `my-journal-audio`)에 파일 그대로 저장해요. 기록이 든 저장 칸은 건드리지 않아서 **예전 기록과 예전 백업 파일은 그대로 열려요.**
- 백업 파일의 모양(`app: 'my-journal'`, `version: 1`)은 그대로이고, 곡마다 첫 녹음이 있을 때만 `audios` 목록이 **더해져요.** 녹음이 없으면 예전 파일과 똑같아요.
- 자동 저장은 이미 글자로 바꿔 둔 첫 녹음을 다시 바꾸지 않고 재사용해요. (12MB 녹음 기준: 처음 변환 약 0.2초, 그다음부터는 거의 0초)
- **⚙ 백업·설정**의 **🎙 녹음** 칸에서 저장된 녹음 용량(MB)을 조용히 볼 수 있어요.
- 사파리 등 IndexedDB를 못 쓰는 환경에서는 녹음을 저장할 수 없어요. 크롬을 권해요.
- 연습 기록을 지워도 곡에 붙은 녹음은 남아요. 녹음은 기록이 아니라 **곡**에 속해 있어서요. (⚙에서 "모든 기록 지우기"를 하면 녹음도 함께 지워져요.)

### 🎴 도장 모음판
- **📅 캘린더** 아래 **🎴 도장 모음판** 버튼 → **한 달에 한 장.** 기록을 남기고 받은 도장이 **받은 순서대로** 차곡차곡 붙어요. (빈 칸이나 남은 칸 수 같은 건 없어요. 받은 도장만 쌓여요.)
- 도장에 **마우스를 올리면 날짜와 기록 제목**이 보이고, **누르면 그 기록으로** 가요. (쉰 날 도장은 그날의 기록 창이 열려요.)
- **◀ 이전 달 / 다음 달 ▶** 로 넘겨요. **쉼 기록은 늘 😴 도장**이에요.

- **📖 이번 달 돌아보기** 창에도 이 달의 도장판이 작게 들어가요.

### ✍ 입력 창이 "무엇을 적으면 좋을지" 이끌어 줘요
기록 종류마다 입력 창이 **두 층**이에요.
1. **기본 층** (항상 보여요): 눌러서 고르는 **칩** 몇 개 + 한 줄 메모 + 연습량·기분. **이것만 채워도 저장돼요.**
2. **✍ 더 적기** (접혀 있어요): 질문 칸들이에요. 새 기록에서는 접혀 있고, **수정할 때 내용이 있으면 펼쳐진 채로** 열려요. 각 칸에는 회색 **예시 문장**이 들어 있어서 뭘 쓰면 되는지 바로 알 수 있어요. **"잘 된 것"이 "어려웠던 것"보다 먼저** 나와요.

### 📚 경제 공부 · 📊 투자 화면 (⚠ 없어짐 — 경제 루틴으로 바뀌었어요)
위쪽 칩이 두 줄로 나뉘어요: **경제 공부 메모 · 📒 용어장 · ❓ 헷갈리는 것** / **투자 기록·복기 · ⏰ 돌아볼 때가 된 기록 · 💡 교훈 모음**
- **📒 용어장**: 공부 메모의 "용어 : 뜻"을 모두 모아 **가나다순**(초성 제목)으로 보여줘요. **검색**도 돼요. 같은 용어를 여러 메모에 적었으면 한 항목에 출처가 함께 나와요. 누르면 그 공부 메모로 이동해서 잠깐 표시돼요.
- **❓ 헷갈리는 것**: 체크하지 않은 질문만 모아 보여줘요. 이해했으면 **그 자리에서 체크**하면 목록에서 빠지고, 체크한 것은 공부 메모 카드에서 계속 볼 수 있어요.
- **⏰ 돌아볼 때가 된 기록**: "언제 돌아볼까?"로 정한 날짜가 지난 **복기 전 기록**만 조용한 목록으로 보여줘요. 빨간 알림 줄이나 숫자 표시는 없어요.
- **복기 쓰기**: 투자 카드의 "복기 쓰기"를 누르면 **질문에 답하는 창**이 열려요. ① 근거는 맞았나?(대체로 맞음·반반·빗나감·아직 모름) ② 기분이 판단에 영향을 줬나?(예·아니오·모르겠음) ③ 다음에도 똑같이 할까?(한 줄) ④ **한 줄 교훈**. 그때 적은 근거도 위에 함께 보여줘요. 예전의 "나중에 돌아본 결과" 칸은 그대로 있고, 새 질문은 따로 저장돼요.
- **💡 교훈 모음**: 복기에서 적은 "한 줄 교훈"을 최신순으로 모아요.
- **칩별 개수**: 투자 기록 위쪽에 "관심 이유: 그냥 친숙해서 3번 · …", "그때 기분: 😌 차분 2번 · …"처럼 **개수만** 보여줘요. 평가하는 말은 없어요.
- 투자는 계속 **기록과 복기 전용**이에요. 시세·매매 추천·수익률·계좌 연결은 없어요.

### 🎻 바이올린: 레슨 때 물어볼 것 · 곡 노트 (지금은 🎻 바이올린 메뉴에 있어요)
- 연습 기록의 **"레슨 때 물어볼 것"**(한 줄에 하나)은 운동·바이올린 화면 맨 위 **레슨 패널의 "🙋 다음 레슨 때 물어볼 것"**에 모여요. 물어봤으면 체크하면 패널에서 빠져요.
- **레슨 기록을 만들 때**(종류를 "레슨"으로 고르면), 창 맨 위에 아직 안 물어본 것이 나타나요. 거기서도 바로 체크할 수 있어요.
- 레슨 패널의 "N/M 완료 · 모두 끝냈어요" 같은 완료 문구는 뺐어요. 체크는 그대로 할 수 있어요.
- **🎼 곡 노트**: 곡 이름(보라색 밑줄)을 누르면 열려요. **곡 메모 한 줄**(백업에 들어가는 일반 기록으로 저장) · 처음 연습한 날 · 연습한 날 수 · 연습량 분포 · **지금 단계**(가장 최근에 고른 "어디쯤") · **잘 된 것 모아보기**(최신순) · 가장 최근 "다음에 해볼 것" · **템포 그래프** · (예전 칸) 어려웠던 점 모아보기.

### 🎨 그림: 필터 · 📺 강의별 보기 (⚠ 없어짐 — 그림 연대기·가져갈 것 모음으로 바뀌었어요)
- 그림 기록장 위에 **종류(전체·모작·창작·연습)**와 **연습 영역** 칩 필터가 있어요. 함께 누르면 둘 다 맞는 것만 보여줘요.
- **📺 강의별 보기**: "참고한 강의·영상 이름"이 같은 그림들을 **날짜순으로 나란히** 보여줘요. (앞뒤 공백만 다른 이름은 같은 강의로 봐요.) 그림을 누르면 크게 볼 수 있어요.

### 📖 이번 달 돌아보기에 더해진 것 (경제 용어·투자 교훈 항목은 ⚠ 없어짐)
**이 달 새로 알게 된 경제 용어 · 이 달의 투자 교훈 · 이 달의 "잘 된 것"**(바이올린 잘 된 것 + 그림 마음에 드는 곳) · 연습량 개수 · 운동 종류별 횟수(요가 N · 슬로조깅 N)가 더해졌어요. 곡 이름은 곡 노트로 이어져요. 지난달과의 비교나 퍼센트는 여전히 없어요.

### 🔀 "기능 확장" 프로젝트와 합쳤어요
다른 대화에서 만든 **"나의 기록장 기능 확장"**(PR #1)의 기능을 이 기록장에 모두 합쳤어요.
- **새벽 4시 전에 남긴 기록은 전날 기록**이에요. 밤 11시에 시작해 자정을 넘겨도 그날 기록이 돼요. (`DAY_STARTS_AT`)
- **오늘 탭**: 바이올린 버튼을 누르면 **최근에 연습한 곡 4개가 칩**으로 나와요. 새벽 4시 전에는 어느 날짜로 남기는지 알려줘요. 오늘 남긴 기록이 없을 때도 안내가 나와요. 슬로조깅 칩에는 🏃가 붙어요.
- **캘린더**: 달력 아래에 **범례**(연습량 견본)가 생겼고, 기록이 있는 날은 옅은 보라색에서 연습량에 따라 진해져요.
- 그림의 **종류(모작·창작·연습)와 참고한 것**, 곡 노트의 **곡 메모**도 그쪽과 같은 이름의 칸이라 그대로 이어져요.
- **그쪽에서 만든 기록과 백업 파일도 그대로 열려요.** (연습량이 글자로, 기분이 이모지로 저장된 것도 이 앱의 값으로 읽어요.)
- 저장 방식이 달랐던 것: 그쪽은 오늘 탭에서 연습량 버튼을 누르면 **바로 저장**됐어요. 이 기록장은 연습량·기분·메모를 **고른 뒤 저장**(또는 같은 큰 버튼을 한 번 더)이에요. 메모까지 남기고 싶을 때 편하도록 이쪽 방식으로 두었어요.

### 🏃 거리(km)와 🎼 템포(BPM)를 다시 넣었어요
이번 요청에 슬로조깅의 거리, 바이올린의 템포, 곡 노트의 템포 그래프가 들어 있어서 다시 넣었어요. 예전에 적어 둔 값도 다시 보여요. 필요 없으면 `app.js` 맨 위 `SCHEMAS`에서 `distance` / `tempo` 줄을 지우면 화면에서 빠져요. (시간(분)은 계속 화면에 없어요.)

### 🧩 오늘 탭 · 연습량 · 기분 · 쉼 · 도장 · 돌아보기 · 그때의 나 (1차)

새로 생긴 칸은 **모두 선택**이에요. 안 적어도 저장돼요. 목표·점수·연속 기록·"N일 빠졌어요" 같은 말은 여전히 없어요.

#### ✏️ 맨 앞의 "오늘" 탭 (사이트를 열면 이 탭이 먼저 보여요)
- 🧘 요가 / 🏃 슬로조깅 / 🎻 바이올린 / 🎨 그림 / 📚 경제 루틴 **큰 버튼**이 있어요. (경제 루틴 버튼은 연습량 대신 체크가 바로 열려요.) 하나를 누르면 아래에 작은 창이 열리고, 거기서 **연습량 → 기분 → 한 줄 메모**를 (고르고 싶은 것만) 고르면 돼요.
- **저장** 버튼을 누르거나, **같은 큰 버튼을 한 번 더** 누르거나, 메모 칸에서 **Enter**를 누르면 오늘 날짜의 **"간단 기록"**으로 저장돼요.
- 저장하면 화면 아래에 **✍ 자세히 적기** 버튼이 나와요. 누르면 그 기록의 수정 창이 열려요. (도장·축하를 꺼 두어도 이 버튼은 나와요.)
- 그 아래에 **오늘 남긴 기록**이 작은 칩으로 모여요. 누르면 고칠 수 있어요.
- 예전에는 마지막에 보던 탭이 열렸는데, 이제는 항상 "오늘" 탭이 열려요. 쉼 버튼은 누르면 남기고 **다시 누르면 지워요.**

#### ●●○ 연습량 3단계 (시간 숫자는 적지 않아요)
- **운동 · 바이올린 연습 · 그림**에 "연습량" 칸이 생겼어요. **살짝 / 적당히 / 듬뿍** 버튼 중 하나를 누르고, **다시 누르면 풀려요.** (레슨과 투자 기록에는 없어요.)
- 카드에는 **●○○ / ●●○ / ●●●** 로 작게 보여요. ⚡ 빠른 기록 창에도 같은 버튼이 있어요.
- **캘린더**: 기록이 있는 날은 옅은 보라색이고, 그날 남긴 기록 중 가장 높은 연습량에 따라 **조금씩 진해져요.** 달력 아래에 견본(범례)도 있어요.
- **주간 요약**: "연습량: 살짝 2 · 적당히 1 · 듬뿍 0"처럼 개수만 보여줘요. 합계 점수는 없어요.

#### 😊 하고 나서 기분
- **운동 · 바이올린 연습·레슨 · 그림 기록**에 "하고 나서 기분" 버튼 3개가 생겼어요. 😊 좋았어요 / 🙂 보통이에요 / 😮‍💨 지쳤어요. 카드 머리줄에 작게 보여요.

#### 😴 쉰 날도 기록
- **오늘 탭**의 "😴 오늘은 쉼" 버튼, 그리고 **캘린더 날짜 창**의 "😴 이 날은 쉼" 버튼을 누르면 쉰 날이 기록돼요. 하루에 하나만 만들어져요.
- 잘못 눌렀다면 다시 누르거나(메모를 적어 둔 쉼은 지우기 전에 물어봐요), 나타나는 **되돌리기**를 누르세요.
- 캘린더에는 색 없이 **😴**만 조용히 나타나고, 주간 요약에는 "쉰 날 N일"만 나와요. 쉰 날도 "기록한 날"에 들어가요.

#### 🎴 도장
- 새 기록을 저장하면 화면 아래에 **랜덤 도장 + 짧은 한 마디**가 잠깐 나타나요. 예) "🎻 오늘도 켰다", "🌙 늦은 밤 수고했어요"
- **밤 10시 이후~새벽 5시 전**에 저장하면 밤 전용 문구에서 골라요.
- 첫 기록이나 "10번째 기록"처럼 딱 떨어지는 숫자에 닿았을 때는 도장 대신 그 축하가 나와요. 기록을 **고칠 때는** 나타나지 않아요.
- 문구는 `app.js` 맨 위의 **`STAMPS`**에서 마음대로 고치거나 더할 수 있어요. 밤 시간은 `NIGHT_START` / `NIGHT_END`예요. **⚙ 백업·설정**에서 끌 수도 있어요.

#### 📖 이번 달 돌아보기
- **📅 캘린더** 아래의 **"📖 이번 달 돌아보기"** 버튼(다른 달을 보고 있으면 "○월 돌아보기")을 누르면 창이 열려요.
- 들어 있는 것: 기록한 날 수(쉰 날 포함) · 종류별 횟수 · 가장 많이 연습한 곡 · 기분 개수 · 첫 그림과 마지막 그림 나란히 · 레슨 피드백 모음. 남긴 것이 없는 항목은 나타나지 않아요.
- 지난달과의 비교, 퍼센트, 목표와의 비교는 없어요. 예시 기록은 세지 않아요.
- 항목은 `app.js`의 **`RECAP_SECTIONS`** 목록에 하나씩 더하는 방식이라, 나중에 경제 용어·투자 교훈 같은 항목을 쉽게 추가할 수 있어요.

#### 🕰 그때의 나
- 오늘 탭 맨 아래에, **한 달 전 → 석 달 전 → 1년 전 오늘**의 기록이 있으면 **한 장만** 보여줘요. (그림 기록이 있으면 그림을 골라 작은 그림으로 보여줘요. 처음 열었을 때 기능을 보여 주려고 예시 기록도 보여줘요.) 없으면 아무것도 나타나지 않아요. 카드를 누르면 그날의 기록 창이 열려요.

#### ⌨️ 키보드 (컴퓨터)
- 입력 창에서 **Cmd+Enter**(Ctrl+Enter도 돼요)로 저장해요.
- **Esc**로 창을 닫아요. 뭔가 적어 둔 창은 닫기 전에 한 번 물어봐요.
- 입력 창이 넓은 화면에 맞게 더 넓어졌어요.

#### 그대로인 것
- 예전 기록과 예전 백업 파일은 그대로 열려요. 백업 파일의 형식은 바뀌지 않았고, 새 칸은 기록에 **더해지기만** 해요.

### ⌚ 워치 캡처 → 클로드 피드백 흐름
**① 워치 캡처 붙이기** (운동 기록)
- 운동 기록에 **워치 캡처** 칸이 생겼어요. 한 기록에 **최대 4장**까지 끌어다 놓거나, 눌러서 고르거나, **Ctrl+V**로 붙여넣을 수 있어요. (휴대폰에서는 앨범에서 고르면 돼요.)
- **🧘 운동·바이올린 화면에 캡처를 바로 끌어다 놓거나 Ctrl+V** 하면, 캡처가 붙은 새 운동 기록 창이 열려요. 날짜는 사진 파일의 날짜로 미리 들어가요. (다르면 고치면 돼요.)
- 카드에는 작은 그림으로 보이고, 누르면 크게 보여요. 큰 사진은 자동으로 줄여서 저장해요.

**② 클로드 피드백 저장** (운동 기록)
- 운동 기록에 **클로드 피드백** 칸이 있어요. 클로드가 해 준 말을 그대로 붙여넣어 두면, 카드의 **💬 클로드 피드백**(눌러서 펼치기)이나 캘린더의 날짜 창에서 나중에 다시 볼 수 있어요.

**③ 클로드에게 보낼 요약 복사 (⚠ 없어짐 — 🆕 🤖 복사칸으로 바뀌었어요)**
- 운동·바이올린 화면의 주간 요약 아래 **📋 클로드에게 보낼 요약 복사** 버튼을 누르면, **위에서 고른 주**의 운동·연습·레슨 기록이 글로 정리돼 창에 나타나고 **자동으로 복사**돼요.
- 클로드 대화창에 붙여넣고(Ctrl+V), **워치 캡처는 함께 올리면** 돼요. (캡처는 그림이라 글에 들어가지 않아요.) 창의 글을 고쳐서 **다시 복사**해도 돼요.
- (예전 설명) 지금은 **🤖 클로드에게 보내기** 복사칸의 "내 정보·요청 문구"에서 바꿔요. 한 기록에 붙일 수 있는 캡처 수는 `SHOT_MAX`예요.

### 🌱 "기록을 잘 남기고 있어요"를 느끼는 기능
점수·목표·연속 기록은 여전히 없어요. 하루 빠져도 끊기는 것이 없고, 쌓인 숫자만 보여줘요. **예시 기록은 세지 않아요.**
- **📅 캘린더 위쪽**: "○월에 기록한 날 · ○○○○년에 기록한 날 · 지금까지 기록한 날"이 며칠인지 보여줘요. 하루에 여러 개를 남겨도 1일이에요. 처음 기록한 뒤 며칠이 지났는지도 알려줘요.
- **🧘 운동·바이올린 위쪽 "지금까지 쌓인 기록"**: 운동 몇 회 · 바이올린 연습한 날 · 연습한 곡 몇 곡 · 레슨 몇 회.
- **🎉 축하 한 줄**: 새 기록을 저장하면 화면 아래에 잠깐 나타나요. 첫 기록이거나 "운동 10번째 기록이에요", "기록한 날이 모두 30일이 되었어요"처럼 딱 떨어지는 숫자에 닿았을 때 나오고, 평소에는 **도장**이 나와요. (위의 🆕 '도장' 참고)

### 🧹 거리(km)와 템포(BPM)를 한 번 없앴다가 다시 넣었어요 (위의 🏃 참고)
- 운동 기록의 **거리(km)** 칸, 바이올린 연습의 **템포(BPM)** 칸과 **템포 그래프**가 없어졌어요. 주간 요약은 **운동 횟수 · 바이올린 연습한 날** 두 가지만 보여줘요.
- 곡 이름은 이제 눌러도 그래프가 열리지 않고 글자로만 보여요.
- 예전에 적어 둔 거리·템포 값은 **화면에서만 숨겨지고** 지워지지 않아요. (수정해서 저장해도 그대로 남고, 백업 파일에도 들어 있어요.)

### 🖼 그림 올리기가 쉬워졌어요
- **그림 기록 추가** 창의 그림 칸이 큰 상자가 되었어요. 사진 파일을 **끌어다 놓거나**, 상자를 **눌러서 고르거나**, 복사·캡처한 그림을 **Ctrl+V로 붙여넣을** 수 있어요. (휴대폰에서는 상자를 누르면 카메라·앨범을 고를 수 있어요.)
- **🎨 그림 기록 화면에 사진을 바로 끌어다 놓으면**, 사진이 붙은 새 그림 기록 창이 열려요. 날짜 칸에는 사진 파일의 날짜가 미리 들어가요. (다르면 고치면 돼요.) 화면에서 Ctrl+V로 붙여넣어도 똑같이 열려요.
- **여러 장을 한꺼번에** 끌어다 놓거나 **🖼 사진 여러 장 올리기** 버튼으로 여러 파일을 고르면, 한 장씩 **"간단 기록"**이 만들어져요. 날짜는 각 파일의 날짜이고, 주제·메모는 나중에 카드의 **수정**에서 채우면 돼요. (이미지가 아닌 파일은 알아서 빼요.)
- 사진을 다른 화면에 잘못 놓아도 브라우저가 사진을 열어 버려서 기록장이 사라지는 일이 없도록 막아 두었어요.
- 큰 사진은 자동으로 줄여서 저장해요. (아이폰 HEIC 사진은 크롬에서 못 열 수 있어요. 사파리에서 열거나 JPG로 바꿔 주세요.)

### 📓 브라우저 탭 아이콘
- 브라우저 탭에 📓 아이콘이 보여요. (별도 이미지 파일 없이 `index.html` 안에 들어 있어요.) 이미 열어 둔 탭에서는 새로고침(F5)하면 바뀌어요.

### ⏱ 시간(분) 칸을 모두 없앴어요
- 운동·바이올린·공부·그림 어디에도 시간(분)을 적는 칸이 없어요. 주간 요약에도 시간은 나오지 않아요.
- 예전에 적어 둔 시간은 **화면에서만 숨겨지고** 지워지지 않아요. (백업 파일에는 그대로 들어 있어요.)

### 📅 캘린더 (새 메뉴)
- 위쪽 메뉴의 **📅 캘린더**에서 한 달 달력으로 기록을 한눈에 볼 수 있어요. **2026년 1월부터** 시작해서 2027년, 2028년… 앞으로도 계속 이어져요. (연도 목록은 앞으로 10년 이상 열려 있어요.)
- 날짜 칸에 그날 한 것이 그림으로 보여요: 🧘 운동 · 🎻 바이올린 연습 · 🎓 레슨 · ✅ 경제 루틴 · 📰 영어 · 🎨 그림. 같은 종류가 여러 개면 작은 숫자가 붙어요. 컴퓨터 화면에서는 제목도 함께 보여요.
- **날짜를 누르면** 그날 기록이 한 창에 모여 보여요. 거기서 **수정·삭제**, 레슨 과제 **체크**, 그리고 **＋ 버튼으로 그 날짜에 기록 추가**를 할 수 있어요. (지난 날짜에 뒤늦게 적을 때 편해요.)
- 위쪽의 종류 버튼(운동 · 바이올린 · 경제 루틴 · 영어 · 그림 · 쉼)을 눌러 보고 싶은 종류만 볼 수도 있어요. **바이올린** 버튼은 연습(🎻)과 레슨(🎓)을 함께 켜고 꺼요. 달력 아래에는 그 달의 기록 개수가 나와요. (목표나 연속 기록 같은 건 일부러 넣지 않았어요.)
- 이 달력은 사이트 안의 달력이에요. 구글 캘린더 같은 외부 서비스와는 연결되지 않아요.

### 💾 자동 저장 (내 컴퓨터의 파일에 저장)
**⚙ 백업·설정 → 자동 저장 켜기**를 누르고 저장할 파일 위치를 **한 번만** 골라 주세요. (예: 문서 폴더의 `나의기록장-자동저장.json`)
- 그 뒤로는 기록을 바꿀 때마다 (1~2초 뒤) 그 파일에 저절로 저장돼요. 백업 파일과 같은 형식이에요.
- 자동 저장이 잘 되는 동안에는 "백업한 지 오래됐어요" 안내가 뜨지 않아요.
- **크롬·엣지(컴퓨터)**에서만 쓸 수 있어요. 사파리·파이어폭스·휴대폰에서는 예전처럼 백업 파일을 가끔 내려받아 주세요.
- 브라우저를 껐다가 다시 열면, 보안 때문에 **위쪽에 "다시 연결"** 안내가 뜰 수 있어요. 누르면 이어서 저장돼요. (멈춰 있는 동안 바꾼 것도 한꺼번에 저장돼요.)

**브라우저 기록을 지운 뒤 되살리는 방법**
- 브라우저에서 "인터넷 사용 기록 삭제"를 할 때 **"캐시된 이미지 및 파일"만** 지우면 기록은 안전해요. 하지만 **"쿠키 및 기타 사이트 데이터"까지 지우면 기록이 사라져요.**
- 그럴 때는 ① `index.html`을 다시 열고 → ② **⚙ 백업·설정 → 백업 파일 불러오기**에서 자동 저장 파일을 고르면 그대로 되살아나요.
  (또는 **자동 저장 켜기**에서 같은 파일을 고르면 "기록이 N개 들어 있어요. 합칠까요?"라고 물어보고 합쳐서 이어가요. 빈 화면이 파일을 덮어쓰지 않아요.)
- 자동 저장 파일은 지우거나 옮기지 말고, 가끔 다른 곳(USB, 클라우드 폴더 등)에 복사해 두면 더 안심이에요.


### 1. 백업 알림
- 마지막으로 **백업 파일을 내려받은 날짜**를 기억해요. **⚙ 백업·설정** 화면에서도 볼 수 있어요.
- 백업한 지 **14일이 지났거나 한 번도 안 했으면**, 화면 위쪽에 빨간 안내 줄이 나타나요.
  예: "마지막 백업 후 16일이 지났어요 [지금 백업] [나중에]"
- **[지금 백업]** 을 누르면 바로 백업 파일이 내려받아지고 안내 줄이 사라져요.
- **[나중에]** 를 누르면 **3일 동안** 안내 줄이 보이지 않아요.
- 기록이 하나도 없을 때는 안내 줄을 띄우지 않아요.
- 몇 일마다 알릴지는 `app.js`의 `BACKUP_REMIND_DAYS`(14), 미루는 기간은 `BACKUP_SNOOZE_DAYS`(3)에서 바꿀 수 있어요.

### 2. 빠른 기록 (⚡ 보라색 버튼)
운동 / 바이올린 / 그림 메뉴마다 **⚡ 빠른 기록** 버튼이 있어요.
날짜(오늘로 미리 채워져 있어요), 종류, 한 줄 메모만 적으면 끝나요.

| 메뉴 | 종류 | 한 줄 메모가 들어가는 곳 |
| --- | --- | --- |
| 운동 / 바이올린 | 요가 · 슬로조깅 / 바이올린 연습 | 운동은 "메모", 바이올린은 "연습한 부분" |
| 그림 | 그대로 모작 / 조금 바꿔 그리기 / 창작 (⚠ 지금 목록) | "그린 것" (단계는 "단계"로 저장돼요) |

- 빠른 기록으로 만든 카드에는 **보라색 "간단 기록"** 표시가 붙어요.
- 나중에 카드의 **수정** 버튼으로 나머지 칸을 채울 수 있어요. 꼭 써야 하는 칸까지 채워서 저장하면 "간단 기록" 표시가 사라져요.
  (예: 곡 이름 없이 빠르게 남긴 바이올린 연습은 곡 이름을 적을 때까지 표시가 남아 있어요.)
- 휴대폰 화면에서는 버튼과 입력 칸이 손가락으로 누르기 편하게 더 크게 보여요.
- 종류 목록은 `app.js` 맨 위의 `QUICK` 부분에서 바꿀 수 있어요.

### 3. 바이올린 레슨 노트
- **레슨 기록**: 바이올린 기록을 추가할 때 **종류**를 "레슨"으로 고르면 **선생님 피드백**과 **다음 레슨까지 과제** 칸만 나타나요.
  과제는 한 줄에 하나씩 적으면 체크박스 목록이 돼요.
- **과제 확인**: 운동·바이올린 메뉴 **맨 위**에 가장 최근 레슨의 과제가 나와요. 그 자리에서 바로 체크하면 저장돼요.
  (레슨 카드 안에서도 체크할 수 있어요. 수정에서 과제를 더 적어도 이미 체크한 것은 그대로예요.)
- **곡 이름**: 연습 기록의 곡 이름 칸을 누르면 **전에 쓴 곡 이름이 자동완성**으로 나타나요.
- 주간 요약의 "바이올린 연습한 날"은 **연습 기록만** 세고, 레슨은 "레슨 N회"로 따로 보여줘요.

### 예전 기록과 백업 파일은 그대로 써요
- 예전에 만든 기록은 그대로 보여요. 종류 칸이 없던 바이올린 기록은 "연습"으로 취급해요.
- 예전에 받은 백업 파일도 그대로 불러올 수 있어요. 백업 파일 형식은 바뀌지 않았어요.

## 글자(항목 이름, 선택지) 바꾸기

`app.js` 파일을 메모장으로 열면 맨 위에 **"1. 설정"** 이 있어요. 여기서 고칠 수 있어요.

```js
{ key: 'kind', label: '종류', type: 'select', options: ['요가', '슬로조깅'], required: true },
```

- **운동 종류 추가**: `options: ['요가', '슬로조깅', '걷기']` 처럼 따옴표로 감싸 쉼표로 이어 붙이기
- **항목 이름 바꾸기**: `label:` 뒤의 글자만 바꾸기
- 따옴표(`'`)와 쉼표(`,`)는 지우지 마세요. 잘못되면 되돌려 놓으면 돼요.
- 색깔은 `style.css` 맨 위 `:root { ... }` 의 색 값을 바꾸면 돼요.
- 파일을 고친 뒤에는 브라우저에서 새로고침(F5)하면 반영돼요. 기존 기록은 그대로예요.
