# 📓 나의 기록장

바이올린 · 운동 · 경제 루틴 · 영어 · 그림을 남기는 **나 혼자 쓰는 기록 사이트**예요.
설치도, 로그인도, 인터넷 연결도 필요 없어요. (**☁ 구글 드라이브 동기화**는 원할 때만 켜는 선택 기능이에요.)

> 📜 바뀐 내역은 [CHANGELOG.md](CHANGELOG.md)에 있어요.

## 실행 방법

**① 파일로 열기** — 이 폴더의 **`index.html`** 을 **더블클릭**하세요. 크롬·엣지·사파리 같은 브라우저가 열리면서 기록장이 나타나요. 끝!
**② 배포된 주소로 열기** — **`https://jennyssam09.github.io/my-journal/`** (GitHub Pages). 다른 기기와 기록을 맞추는 **☁ 구글 드라이브 동기화**는 이 주소에서만 쓸 수 있어요. (만드는 방법은 아래 「☁ 구글 드라이브 동기화」)

- 두 방법은 **저장 공간이 서로 달라요.** 파일로 쓰던 기록을 배포 주소로 옮기려면 백업 파일로 옮겨요. (아래 2단계)
- 처음 열면 **예시 기록**이 들어 있어요. 어떤 모습인지 보여 주려는 것이라 **⚙ 백업·설정 → 예시 기록만 지우기**로 지울 수 있어요. (내 기록은 그대로 남고, 한 번 지우면 다시 생기지 않아요.)
- 새 버전이 안 보이면 브라우저가 옛 화면을 기억하는 거예요. 배포 주소에서 **Cmd + Shift + R**(강제 새로고침)을 해 주세요.

메뉴는 **📅 캘린더 · 🎻 바이올린 · 🧘 운동 · 📚 경제 루틴 · 📰 영어** 예요. 처음 열면 **이번 달 캘린더**가 먼저 보여요. 그림은 메뉴에 없고 **⚙ 백업·설정 → 🎈 놀이터**로 들어가요.

## 메뉴별 기록법

기록 추가는 각 메뉴의 **＋ 버튼**, 고치기는 카드의 **수정**, 지우기는 카드의 **삭제**(한 번 더 물어봐요)예요. 입력 창에서는 **Enter**(한 줄 칸) 또는 **Cmd/Ctrl + Enter** 로 저장하고 **Esc** 로 닫아요. 한글을 치는 도중의 Enter 는 글자를 확정할 뿐 저장하지 않아요. 새벽 4시 전에 입력 창을 열면 "어제 기록으로 남겨요" 안내가 나와요. (하루가 바뀌는 시각은 `DAY_STARTS_AT`)

🎻 바이올린 · 🧘 운동 · 📰 영어 · 📚 경제 루틴 화면은 **같은 틀**이에요. 위에서 아래로 **제목과 설명 한 줄 → ＋ 기록 버튼 → 칩 줄(맨 앞 칩이 늘 기본이에요: 📖 기록 · 📖 기사 · ✅ 오늘 루틴) → 요약 한 줄 → 목록**이에요. 다른 메뉴에 갔다 오면 칩은 늘 맨 앞으로 돌아와요. 요약 한 줄은 이번 주에 한 것만 작게 보여 주고, 보여 줄 게 없으면 줄이 없어요. 기록이 하나도 없으면 "다음에 뭘 하면 되는지"만 안내해요.

| 메뉴 | 이렇게 남겨요 |
| --- | --- |
| 📅 **캘린더** | 한 달 달력에 그날 한 것이 그림으로 보여요 (🧘 운동 · 🎻 연습 · 🎓 레슨 · ✅ 경제 루틴 · 📰 영어 · 🎨 그림). **날짜를 누르면** 그날 기록이 모여 보이고, 거기서 수정·삭제·**＋ 기록 더하기**(지난 날짜에 뒤늦게 적을 때)·**😴 이 날은 쉼**을 할 수 있어요. 위쪽 칩으로 보고 싶은 종류만 볼 수 있고, **[오늘]** 은 이번 달로 이동만 해요. 달력 아래에는 **▸ 🤖 클로드에게 보내기** · **📖 이번 달 돌아보기** · **💮 도장 모음판** · **🕰 그때의 나**(한 달·석 달·1년 전 오늘)가 있어요. |
| 🎻 **바이올린** | **＋ 바이올린 기록** → 날짜 · 종류(**연습 / 레슨**) · 곡 이름(전에 쓴 곡이 자동완성돼요) · 오늘 한 것 · 교재(⚙︎ 교재 관리) · 연습량 · 기분. **✍ 더 적기**(접혀 있어요)에는 잘 된 것 · 다음에 해볼 것 · 레슨 때 물어볼 것 · 템포(BPM) · 연습한 부분(한 줄) · 🎙 녹음이 있어요. 종류를 **레슨**으로 고르면 선생님 피드백 · 다음 레슨까지 과제가 나오고, 과제는 📖 기록 칩의 맨 위에서 바로 체크해요. **곡 이름을 누르면 곡 노트**(템포 그래프 · 🎙 녹음 올리기 — 휴대폰 녹음 파일을 끌어다 놓기)가 열려요. 칩은 **📖 기록 · 📚 레퍼토리 책장 · 💬 피드백**이에요. 요약 한 줄은 "이 주에 연습한 곡: … · 다음에 해볼 것: …"이고, 목록 맨 아래의 **🌱 지금까지 쌓인 기록**은 첫 기록으로부터 10일이 지난 뒤에 숫자가 나와요. (그전에는 "이제 시작했어요"만) |
| 🧘 **운동** | **＋ 운동 기록** → 날짜 · 종류(요가 / 슬로조깅) · 거리(슬로조깅만) · 운동량 · 기분 · 한 줄. 이게 전부예요. 칩은 **📖 기록 · 💬 피드백**이고, 요약 한 줄은 "이 주: 요가 2 · 슬로조깅 1"처럼 한 것만 보여요. 🌱 쌓인 기록은 바이올린과 같아요. |
| 🎈 **놀이터** (그림) | ⚙ 백업·설정 → **🎈 놀이터 → 들어가기**. 지금까지 그린 것이 갤러리로만 보여요. **＋ 그림 올리기** → 사진(여러 장 가능 · 끌어다 놓기 · Ctrl+V 붙여넣기 · 큰 사진은 자동으로 줄여서 저장) · 종류(크로키 / 모작 / 창작) · 연습량 · 한 줄. 썸네일을 누르면 상세 창(모작에 원본 사진을 넣었으면 "원본 \| 내 그림" 나란히)이 열려요. **← 캘린더로** 로 돌아와요. 안 그리는 날에는 어디에도 나타나지 않아요. |
| 📚 **경제 루틴** | 칩은 **✅ 오늘 루틴 · 💬 피드백**이에요. 🎧 경제 팟캐스트 · 📮 뉴스레터 **체크만 하면 바로 저장**돼요(뉴스레터 칩도 눌러요). **오늘 한 줄**은 **[저장]** 이나 Enter 로 저장하고, 저장 안 한 채 다른 메뉴로 가면 물어봐요. 이번 주 점과 **지난 한 줄 보기**가 있어요. |
| 📰 **영어** | **＋ 이번 주 기사 추가** → 링크 · 제목 · 세 줄 요약 · 표현. 칩은 **📖 기사 · 💬 표현 모음 · 🗣 말해 볼 주제 · 💬 피드백**이고, 목록 위에 "이번 주 ✓" 표시가 한 줄로 있어요. 카드의 **🤖 첨삭 받기**로 클로드에게 보내요. |

- 📖 **이번 달 돌아보기**(캘린더 아래)는 그 달에 남긴 것을 개수 위주로 한눈에 보여 줘요. 점수·목표·연속 기록·"N일 빠졌어요" 같은 말은 일부러 넣지 않았어요.
- 🧘 운동은 "운동량", 🎻 바이올린·🎨 그림은 "연습량" 이라고 불러요. (살짝 · 적당히 · 듬뿍)

## 🤖 클로드에게 보내기와 받은 피드백

**기록 → 클로드에게 보내기 → 받은 피드백 저장 → 해볼 것 하나 → 다음 기록에 반영.** 이 한 바퀴가 목적이에요. 밖으로 나가는 요청은 없고, **복사해서 붙여 넣는 방식**이에요.

1. **복사하기** — 📅 캘린더 아래 **▸ 🤖 클로드에게 보내기**(눌러서 펼쳐요)에서 **기간**(오늘 / 이번 주 / 이번 달)과 **범위**(🎻 · 🧘 · 📚 · 📰)를 고르면 보낼 글이 미리 보기로 나와요. 미리 보기는 **고쳐도 돼요.** "이번에 특히 물어볼 것"도 적을 수 있어요. **📋 복사하기**를 눌러 클로드 대화창에 붙여 넣어요. 카드의 **🤖** 는 **그 기록 하나만** 복사해요. (그림은 글에 못 들어가니 이미지를 직접 첨부해요.)
   - 글 순서: 내 정보 → 요청 문구 → 특히 물어볼 것 → 지난번 받은 제안(해봤음 / 아직) → 기록 본문 → 요약 한 줄(이번 주·이번 달일 때)
2. **답변 저장** — 복사하면 **💬 받은 피드백 붙여넣기**가 열려요. 답변을 붙여 넣고 **이번에 해볼 것 하나**를 적어 저장해요. 카드의 🤖 로 보낸 답변은 그 카드 안에 붙여 넣어요 (카드에 **💬 1** 배지가 생겨요).
3. **다시 보기** — 각 메뉴의 **💬 피드백** 칩에 받은 피드백이 최신순으로 나와요. 각 피드백의 **해볼 것** 옆 체크가 **해봤음**이에요. 수정·삭제·기록 보기도 있어요.
4. **해볼 것 하나 해 보기** — 아직 안 해본 해볼 것이 입력 창 맨 위에 **"💡 지난 피드백에서: …"** 로 나와요. **☐ 오늘 해봤음**에 체크하고 저장하면 그 기록에 연결돼요. (안 뜨게 하려면 **✕ 숨기기**. 💬 피드백에는 그대로 남아요.) 📚 경제 루틴 화면에서는 체크 목록 아래 한 줄로 나와요.
5. **✎ 내 정보·요청 문구** — 복사칸의 버튼. 범위(🎻 · 🧘 · 📚 · 📰 · 🎨)별로 고치고, **기본값으로 되돌리기**도 돼요. **저장**을 눌러야 저장돼요. 처음 문구는 `app.js` 맨 위 **`CLAUDE_SCOPES`**, 공통 문장은 **`CLAUDE_COMMON`** 이에요. 백업에도 들어가요.

## ☁ 구글 드라이브 동기화 (선택)

아이맥과 갤럭시 Z 폴드가 **같은 기록**을 보게 해 줘요. 켜지 않아도 지금까지처럼 **`index.html`을 더블클릭해서 쓰는 방식은 그대로** 돼요. (동기화는 **배포된 주소**에서만 쓸 수 있어요.)

- 내 **구글 드라이브의 "나의 기록장 (동기화)" 폴더** 하나만 써요. 내 다른 파일은 볼 수 없어요. (권한은 `drive.file` 하나예요.)
- 서버도, 비밀번호도, 비밀 키도 없어요. 로그인 정보(토큰)는 **저장하지 않고** 창을 닫으면 사라져요.
- **기록 글은 `journal.json` 하나**, **그림은 한 장에 파일 하나**로 올라가요.
- 🎙 **녹음도 한 개에 파일 하나(`audio-…`)로 올라가요.** 파일로 열었거나 로그인하지 않았을 때는 이 기기에만 저장돼요. (백업 파일의 "곡마다 첫 녹음"과는 별개예요.)

### 1단계. 배포하기 (GitHub Pages)

> ⚠️ **먼저 저장소 이름부터 바꿔 주세요.**
> 지금 저장소 이름이 내 GitHub 아이디와 같아서(`jennyssam09/jennyssam09`), GitHub가 이 저장소를 **"프로필 저장소"**로 보고 **이 README를 내 GitHub 프로필 첫 화면에 보여 줘요.** 이름을 `my-journal` 로 바꾸면 그런 일이 없어요.

**① 저장소 이름 바꾸기** (웹사이트에서)
1. 저장소 페이지 → 위쪽 **Settings**(설정) → 첫 화면 **General** 의 **Repository name** 칸에 `my-journal` 을 적고 **Rename**(이름 변경)을 눌러요.
2. 예전 주소로 들어가도 GitHub가 새 주소로 넘겨 주지만, 아래처럼 **내 컴퓨터의 git 주소도 바꿔 두는 걸 권해요.**

**② 내 컴퓨터의 git 원격 주소 바꾸기** (터미널)
```
cd 나의기록장폴더            # index.html이 들어 있는 폴더
git remote -v               # 지금 주소 확인 (jennyssam09/jennyssam09 로 보이면 바꿔야 해요)
git remote set-url origin https://github.com/jennyssam09/my-journal.git
git remote -v               # my-journal 로 바뀐 걸 확인
git fetch                   # 잘 연결됐는지 확인 (오류가 없으면 끝)
```
(ssh 주소를 쓰고 있다면 `git@github.com:jennyssam09/my-journal.git` 로 바꿔요. 다른 사람 아이디라면 `jennyssam09` 자리를 내 아이디로 읽어 주세요.)

**③ 저장소를 공개(Public)로** — 무료 GitHub Pages는 공개 저장소에서만 돼요.
Settings → 맨 아래 **Danger Zone** → **Change repository visibility** → **Public**.
공개해도 **내 기록은 보이지 않아요.** (기록은 내 Drive와 내 브라우저에만 있어요.) 앱 코드와 예시 문구만 누구나 볼 수 있어요.

**④ 기본 브랜치를 `main` 으로 바꾸고, 이 작업을 합치기**
GitHub Pages는 `main` 을 기준으로 올리는 게 편한데, **이 저장소의 기본 브랜치 이름은 지금 `main` 이 아니라 `claude/clever-edison-2uvnkz` 예요.** 먼저 이름을 바꿔 주세요.
1. 저장소 **Settings** → **General**(또는 **Branches**) → **Default branch** 옆의 ✏️ 연필(**Rename branch**) → `main` 으로 바꾸고 **Rename**. (열려 있는 PR은 새 이름을 자동으로 따라가요.)
2. **Pull requests** 탭에서 이 작업의 PR(**#2**)을 열어 **Merge pull request** 를 눌러요. → `main` 에 이 앱이 통째로 들어가요.
3. 예전 PR **#1** ("Add quick daily logging…")은 그 내용이 이미 이 앱에 합쳐져 있어서 **Close**(닫기)만 해 주세요. (합치면 충돌이 나요.)
4. 내 컴퓨터에서는 `git fetch --prune` 다음 `git checkout main` 으로 새 이름의 브랜치를 받아 써요.

**⑤ GitHub Pages 켜기**
1. Settings → 왼쪽 **Pages**
2. **Source**: `Deploy from a branch` / **Branch**: `main` (④에서 바꾼 이름) , 폴더 `/ (root)` → **Save**
3. 1~2분 기다리면 위쪽에 주소가 나와요. 이 앱의 주소는 **`https://jennyssam09.github.io/my-journal/`** 처럼 생겼어요. (`jennyssam09` 자리는 내 아이디)
4. 그 주소를 열어 기록장이 보이면 배포 성공이에요. (처음엔 **기록이 비어 있어요** — 아래 2단계로 옮겨요.)

### 2단계. 예전 기록을 배포 주소로 옮기기

파일(`index.html`)로 열어 쓰던 기록은 **배포된 주소의 기록과 저장 공간이 서로 달라요.** 백업 파일로 옮겨요.
1. **예전 방식**(index.html 더블클릭)으로 열어서 **⚙ 백업·설정 → 백업 파일 내려받기**
2. **배포된 주소**를 열어서 **⚙ 백업·설정 → 백업 파일 불러오기** → 방금 받은 파일 고르기
3. 위쪽 **☁ 로그인** → 구글 로그인 → 처음 연결이라 Drive가 비어 있으면 **이 기기 기록이 자동으로 올라가요.**
4. 다른 기기(폴드)에서는 배포된 주소를 열고 ☁ 로그인만 하면 **Drive의 기록을 받아 와요.** (그 기기에 기록이 없으면 물어보지도 않아요.)

### 3단계. 구글 설정 (클라이언트 ID 만들기)

> 콘솔 화면 이름은 구글이 자주 바꿔요. 이름이 조금 달라도 비슷한 메뉴를 찾아 주세요. 지금은 **"Google Auth Platform"** 이라는 이름이에요.

1. https://console.cloud.google.com 에 **내 구글 계정**으로 들어가서 **프로젝트 만들기** (이름 예: `my-journal`)
2. **API 및 서비스 → 라이브러리 → "Google Drive API" → 사용**
3. **Google Auth Platform → 시작하기**: 앱 이름(예: 나의 기록장), 지원 이메일, 대상 **외부(External)**, 연락처 이메일을 넣어요.
4. **데이터 액세스(범위)** 에는 **`.../auth/drive.file` 하나만** 추가해요. (다른 것은 넣지 마세요.)
5. **대상(Audience)**: 처음에는 **테스트** 상태로 두고, **테스트 사용자에 내 Gmail을 추가**해요. (폴드에서 쓰는 계정도 같은 계정이면 됩니다.)
6. **클라이언트 → 클라이언트 만들기 → 웹 애플리케이션**
   - **승인된 JavaScript 원본**: `https://jennyssam09.github.io` ← **주소 맨 뒤 `/` 와 `/my-journal/` 같은 경로는 붙이지 마세요.**
   - (컴퓨터에서 시험하려면 하나 더) `http://localhost:8000`
   - **승인된 리디렉션 URI 는 비워 둬요.** (이 앱이 쓰는 방식은 필요 없어요.)
7. 만들어지면 나오는 **클라이언트 ID** (`…apps.googleusercontent.com`)를 복사해서 **`sync-config.js`** 를 열어 붙여 넣어요.
   ```js
   window.SYNC_CONFIG = {
     clientId: '여기에-클라이언트-ID.apps.googleusercontent.com',
     deployUrl: 'https://jennyssam09.github.io/my-journal/',
     folderName: '나의 기록장 (동기화)',
   };
   ```
   - 클라이언트 ID는 **비밀이 아니라서** 저장소에 올려도 돼요.
   - **"클라이언트 보안 비밀번호(secret)"는 어디에도 붙여 넣지 마세요.** 이 앱은 필요 없어요.
8. 고친 `sync-config.js` 를 저장소에 올려요 (`git add sync-config.js && git commit -m "클라이언트 ID" && git push`, 또는 GitHub 웹에서 파일을 열어 ✏️ 로 고치기). 1~2분 뒤 배포 주소에 반영돼요.
9. 설정이 반영되기까지 **몇 분에서 몇 시간** 걸릴 수 있어요. 로그인 창에 오류가 나면 잠깐 기다렸다가 다시 해 보세요.

**테스트 상태로 시작해요.** 이 상태에서는 **테스트 사용자로 넣은 계정만** 로그인할 수 있고, 구글이 **약 7일마다 로그인 허용을 다시 물어볼 수 있어요.** (그럴 땐 위쪽 칩이 "다시 연결"로 바뀌니 한 번 누르면 돼요.)

**프로덕션(게시)으로 바꾸는 방법** — 7일마다 다시 묻는 일을 없애고 싶을 때
1. Google Auth Platform → **대상(Audience)** → **앱 게시(Publish app)** → 확인 → 상태가 **"프로덕션"** 으로 바뀌어요.
2. 이 앱이 쓰는 `drive.file` 은 **민감하지 않은 범위라서 따로 심사 없이 게시할 수 있는 것으로 알고 있어요.** (구글 정책은 바뀔 수 있으니 콘솔에 나오는 안내를 꼭 확인하세요.)
3. 게시한 뒤에는 테스트 사용자 목록이 필요 없어요. 처음 로그인할 때 "Google에서 확인하지 않은 앱" 안내가 나오면 **고급 → 나의 기록장(안전하지 않음)으로 이동**을 누르면 돼요. (내가 만든 앱이라서요.)

### 4단계. 써 보기

위쪽 **☁ 칩**이 동기화 상태를 알려 줘요. 누르면 자세히 보는 창이 열려요.

| 칩 | 뜻 |
| --- | --- |
| ☁ 배포된 주소에서 사용할 수 있어요 | 파일(index.html)로 열었어요. 동기화만 꺼져 있고 나머지는 다 써져요. |
| ☁ 설정 필요 | `sync-config.js` 에 클라이언트 ID가 비어 있어요. |
| ☁ 로그인 | 아직 로그인하지 않았어요. 눌러서 로그인해요. |
| ☁ ✓ 동기화됨 · 3분 전 | 잘 맞춰져 있어요. ("동기화 중…"은 올리거나 받는 중이고, "대기 중 · 2개 (오프라인)"은 인터넷이 없어서 연결되면 알아서 올린다는 뜻이에요.) |
| ☁ ⚠ 다시 연결 | 로그인이 풀렸어요. **칩을 한 번만 누르면** 구글 로그인 창이 떠요. 연결되면 쌓인 변경이 바로 올라가요. |
| ☁ ⚠ 충돌 2개 | 두 기기에서 같은 기록을 다르게 고쳤어요. 눌러서 **이 기기 것 / Drive 것 / 둘 다 남기기** 중에 골라요. (고르기 전까지 이 기기의 기록은 그대로예요.) |
| ☁ ⚠ 오랜만이에요 | 60일 넘게 동기화하지 않았어요. **"Drive 기준으로 새로 받기 (추천)"** 또는 **"그래도 합치기"** 를 골라요. (새로 받기 전에 이 기기 백업 파일이 자동으로 내려받아져요.) |
| ☁ ⚠ Drive 파일이 없어요 / 동기화 실패 | 눌러서 이유를 보고, 이 기기 기록으로 다시 만들거나 자동으로 다시 시도하게 둬요. |

**언제 동기화하나요?** 사이트를 열 때 · 로그인할 때 · 기록을 저장하고 5초쯤 뒤 · 다른 창에 갔다가 돌아왔을 때 · 인터넷이 다시 연결될 때 · 상세 창의 **지금 동기화**를 눌렀을 때.

**처음 로그인** — 이 기기에 이미 기록이 있으면 먼저 **백업 파일이 자동으로 내려받아져요**(`my-journal-backup-before-sync-날짜.json`). Drive가 비어 있으면 이 기기 기록을 올리고, Drive에도 기록이 있으면 **합치기 (추천)** · **이 기기 → Drive 덮어쓰기** · **Drive → 이 기기 덮어쓰기** 중에 물어봐요.

**로그아웃** — 구글 연결을 끊고 메모리의 로그인 정보를 지워요. **이 기기의 기록은 그대로** 남아요. (같은 계정으로 다시 로그인하면 이어서 동기화돼요.)

> **모든 기록 지우기**(⚙ 백업·설정)는 동기화가 켜져 있으면 **Drive와 다른 기기에서도 지워져요.** 이 기기에서만 지우려면 먼저 로그아웃하세요.

**알아 둘 것**
- **Drive 폴더 안의 파일(`journal.json`, `img-…`, `audio-…`)은 지우거나 옮기거나 이름을 바꾸지 마세요.** 그러면 앱이 "Drive 파일이 없어요"라고 알려 줘요.
- **구글 클라이언트 ID를 새로 만들면** 예전 ID로 만든 Drive 파일이 새 ID에서는 보이지 않아요(`drive.file` 은 "이 앱이 만든 파일"만 보여요). 한 번 정한 ID는 계속 쓰세요.
- 지운 기록은 "삭제 표시"로 60일 남아요. 큰 그림이 많으면 처음 동기화가 몇 분 걸려요. 🎙 녹음은 파일 하나씩 올라가고, 다른 기기에서는 **☁ 눌러서 받기**를 눌러야 내려받아요.
- 기록은 **내 브라우저와 내 구글 드라이브**에만 있어요. 이 앱의 서버는 없어요. 접근을 끊으려면 ☁ → **로그아웃**, 또는 https://myaccount.google.com/permissions → "나의 기록장" → **액세스 삭제**.

## 💾 백업 · 자동 저장

기록은 **이 브라우저 안에** 저장돼요. 새로고침하거나 껐다 켜도 남아 있지만, **"쿠키 및 기타 사이트 데이터" 삭제**를 하거나 **다른 브라우저·다른 컴퓨터**로 열면 보이지 않아요. 항상 같은 브라우저(예: 크롬)로 여는 걸 권해요.

- **백업 파일** — **⚙ 백업·설정 → 백업 파일 내려받기**로 파일을 저장하고, **백업 파일 불러오기**로 되살려요. (그림 · 받은 피드백 · 내 정보·요청 문구 · 교재 목록이 함께 들어가요.) 예전에 받은 백업 파일도 그대로 열려요. 파일의 형식은 `{ app: 'my-journal', version: 1, records: […] }` 이에요.
- **백업 알림** — 마지막 백업이 **14일** 넘었거나 한 번도 안 했으면 위쪽에 빨간 안내 줄이 떠요. **[지금 백업]** 을 누르면 바로 내려받고, **[나중에]** 는 3일 동안 숨겨요. (`BACKUP_REMIND_DAYS` · `BACKUP_SNOOZE_DAYS`)
- **💾 자동 저장** (크롬·엣지 컴퓨터만) — **⚙ 백업·설정 → 자동 저장 켜기**에서 저장할 파일 위치를 **한 번만** 골라요. 그 뒤로는 기록을 바꿀 때마다 1~2초 뒤 저절로 저장돼요. 브라우저를 껐다 켜면 위쪽에 **"다시 연결"** 이 뜰 수 있는데 한 번 누르면 이어져요.
- **되살리기** — 사이트 데이터를 지웠다면 `index.html` 을 다시 열고 **⚙ 백업 파일 불러오기**에서 백업(또는 자동 저장) 파일을 골라요. 자동 저장 파일은 지우거나 옮기지 말고, 가끔 USB나 클라우드 폴더에 복사해 두면 더 안심이에요.
- 🎙 **녹음**은 백업 파일에 **곡마다 첫 녹음만** 들어가요. 나머지는 ☁ 동기화를 켜면 Drive에 올라가고, 안 켰다면 이 브라우저에만 있어서 사이트 데이터를 지우면 사라져요. 큰 파일이라 싫으면 **"녹음은 백업에서 빼기"** 를 켜요.
- 다른 기기에서도 보고 싶다면 **☁ 구글 드라이브 동기화**를 켜세요.

## 자주 고칠 만한 설정

`app.js` 를 메모장으로 열면 맨 위에 **"1. 설정"** 이 있어요. 고친 뒤에는 브라우저에서 새로고침(F5)하면 반영되고, 기존 기록은 그대로예요. 따옴표(`'`)와 쉼표(`,`)는 지우지 마세요. 잘못되면 되돌려 놓으면 돼요.

| 이름 | 무엇을 바꾸나요 |
| --- | --- |
| `CHIPS` | 칩(눌러서 고르는 버튼)의 선택지 — 바이올린 "오늘 한 것" |
| `DAY_STARTS_AT` | 하루가 바뀌는 시각 (기본: 새벽 4시. 자정으로 하려면 0) |
| `AMOUNTS` / `MOODS` | 연습량 · 기분 버튼의 이름과 그림 |
| `STAMPS` | 도장과 한 마디 문구 (종류별 · 밤 전용) |
| `NIGHT_START` / `NIGHT_END` | 밤 문구를 쓰는 시간 (기본: 밤 10시 ~ 새벽 5시 전) |
| `MEMORY_LOOKBACKS` | "그때의 나"가 찾는 시점 (한 달 · 석 달 · 1년 전) |
| `RECAP_SECTIONS` | 이번 달 돌아보기에 들어가는 항목들 |
| `CLAUDE_SCOPES` / `CLAUDE_COMMON` | 🤖 범위별 "내 정보"·"요청 문구"의 처음 값 / 모든 요청 끝에 붙는 공통 문장 |
| `TEXTBOOKS_DEFAULT` | 교재 칩의 처음 목록 (그 뒤로는 ⚙︎ 교재 관리에서 바꿔요) |
| `ECON_ROUTINES` | 경제 루틴 체크 항목(뉴스레터 칩 포함) |
| `PLAYGROUND` | 🎈 놀이터의 아이콘과 이름 |
| `EMPTY_TEXT` | 기록이 없을 때 보이는 안내 문구(바이올린·운동·영어·책장·피드백…) |
| `TOTALS_AFTER_DAYS` | 🌱 "지금까지 쌓인 기록"에 숫자를 보여 주기 시작하는 날수 (기본 10일) |
| `SEASON_DECOR` | 달마다 바뀌는 계절 장식 이모지 (⚙ 백업·설정에서 끌 수 있어요) |
| `AUDIO_MAX_PER_PIECE` / `AUDIO_MAX_SECONDS` / `AUDIO_MAX_BYTES` | 곡당 녹음 개수(5) · 한 파일 최대 길이(5분) · 최대 크기(15MB) |
| `sync-config.js` | ☁ 동기화: 구글 클라이언트 ID · 배포 주소 · Drive 폴더 이름 (app.js가 아니라 이 파일에서 바꿔요) |
| `?v=…` (`index.html`) | 파일 이름 뒤의 번호. 버전이 바뀌면 브라우저가 새 파일을 받아요. |

**항목 이름·선택지 바꾸기** — 예를 들어 운동 종류는 이 한 줄이에요. `options` 에 `'걷기'` 를 더하면 종류가 늘어나고, `label:` 뒤의 글자만 바꾸면 항목 이름이 바뀌어요. 색은 `style.css` 맨 위 `:root { … }` 의 값을 바꿔요.

```js
{ key: 'kind', label: '종류', type: 'select', options: ['요가', '슬로조깅'], required: true },
```

**파일** — `index.html`(뼈대, 더블클릭해서 여는 파일) · `style.css`(색과 모양) · `app.js`(동작과 항목 설정) · `sync.js`(☁ 동기화 동작) · `sync-config.js`(☁ 설정) · `README.md`(이 설명서) · `CHANGELOG.md`(바뀐 내역)
