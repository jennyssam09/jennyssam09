# 📓 나의 기록장

운동·바이올린, 경제 공부·투자, 그림 연습을 남기는 **나 혼자 쓰는 기록 사이트**예요.
설치할 것도, 로그인도, 인터넷 연결도 필요 없어요.

## 실행 방법

1. 이 폴더에서 **`index.html`** 파일을 **더블클릭**하세요.
2. 크롬, 엣지, 사파리 같은 브라우저가 열리면서 기록장이 나타나요. 끝!

> 처음 열면 **예시 기록**이 들어 있어요. 어떤 모습인지 보여 주려는 것이라 언제든 지울 수 있어요.

## 기본 사용법

| 하고 싶은 일 | 방법 |
| --- | --- |
| 기록 추가 | 각 메뉴의 **＋ 버튼** → 칸을 채우고 **저장** (`*` 표시는 꼭 써야 하는 칸) |
| 기록 고치기 | 기록 카드의 **수정** 버튼 |
| 기록 지우기 | 기록 카드의 **삭제** 버튼 (한 번 더 물어봐요) |
| 그림 넣기 | 그림 기록 추가 → **그림 이미지**에서 파일 선택 (큰 사진은 자동으로 줄여서 저장해요) |
| 워치 캡처 넣기 | 운동·바이올린 화면에 캡처를 **끌어다 놓기 / Ctrl+V**, 또는 운동 기록의 **워치 캡처** 칸 |
| 클로드에게 물어보기 | 주간 요약의 **📋 클로드에게 보낼 요약 복사** → 대화창에 붙여넣고 캡처와 함께 보내기 |
| 그림 비교하기 | 그림 메뉴의 **↔ 나란히 비교**, 또는 카드의 **이전 작업과 비교** |
| 주간 요약 보기 | 운동·바이올린 메뉴 위쪽. **◀ 이전 주 / 다음 주 ▶** 로 이동 (월요일~일요일 기준) |
| 가볍게 오늘 기록 | **✏️ 오늘** 탭의 큰 버튼 → 연습량·기분·메모(선택) → 저장 (같은 버튼을 한 번 더 눌러도 저장) |
| 쉰 날 남기기 | 오늘 탭의 **😴 오늘은 쉼**, 또는 캘린더 날짜 창의 **😴 이 날은 쉼** |
| 한 달 돌아보기 | 📅 캘린더 아래 **📖 이번 달 돌아보기** |
| 무엇을 적을지 막막할 때 | 입력 창의 칩만 고르고 저장 → 나중에 카드의 **수정**에서 **✍ 더 적기**를 펼쳐 질문에 답하기 |
| 헷갈리는 것·용어 모아 보기 | 📚 경제 화면의 **❓ 헷갈리는 것**, **📒 용어장** |
| 투자 복기하기 | 투자 카드의 **복기 쓰기** → 질문에 답하기 (⏰ 돌아볼 때가 된 기록에서도 시작할 수 있어요) |
| 밤 모드 | 오른쪽 위 **🌙** 버튼 |
| 입력 창 저장·닫기 | **Cmd+Enter** 저장 · **Esc** 닫기 |

투자 기록은 **기록과 복기만** 할 수 있어요. 매매를 추천하거나 주문하는 기능, 계좌 연결은 없어요.

## 예시 기록 지우기

오른쪽 위 **⚙ 백업·설정** → **예시 기록만 지우기**.
내가 쓴 기록은 그대로 남아요. (예시를 직접 수정하면 내 기록이 되어 남아요.)
한 번 지우면 예시는 다시 생기지 않아요.

## ⚠️ 꼭 알아 두세요: 기록은 이 브라우저 안에 저장돼요

> 💡 아래의 **자동 저장**(💾)을 켜 두면 안심이에요. 아래 "자동 저장" 설명을 꼭 읽어 보세요.

- 새로고침하거나 브라우저를 껐다 켜도 기록은 남아 있어요.
- 하지만 **"방문 기록·사이트 데이터 삭제"** 를 하거나 **다른 브라우저·다른 컴퓨터**로 열면 보이지 않아요.
- 그래서 가끔 **⚙ 백업·설정 → 백업 파일 내려받기**로 파일을 저장해 두세요. (그림까지 다 들어 있어요.)
- 백업 파일은 같은 화면의 **백업 파일 불러오기**로 되살릴 수 있어요.
- 항상 같은 브라우저(예: 크롬)로 여는 것을 권해요.

## 🆕 이번에 바뀐 것

새로 생긴 칸은 **모두 선택**이에요. 안 적어도 저장돼요. 목표·점수·연속 기록·"N일 빠졌어요" 같은 말은 여전히 없어요.

### ✍ 입력 창이 "무엇을 적으면 좋을지" 이끌어 줘요
기록 종류마다 입력 창이 **두 층**이에요.
1. **기본 층** (항상 보여요): 눌러서 고르는 **칩** 몇 개 + 한 줄 메모 + 연습량·기분. **이것만 채워도 저장돼요.**
2. **✍ 더 적기** (접혀 있어요): 질문 칸들이에요. 새 기록에서는 접혀 있고, **수정할 때 내용이 있으면 펼쳐진 채로** 열려요. 각 칸에는 회색 **예시 문장**이 들어 있어서 뭘 쓰면 되는지 바로 알 수 있어요. **"잘 된 것"이 "어려웠던 것"보다 먼저** 나와요.

| 기록 | 기본 층 | ✍ 더 적기 |
| --- | --- | --- |
| 🧘 요가 | 주로 한 것(스트레칭·코어·밸런스·호흡·영상) | 시원했던 곳 · 몸이 어땠나 한 줄 · 따라 한 영상·수업(+링크) |
| 🏃 슬로조깅 | 거리(km) · 날씨 | 장소 · 대화할 수 있는 속도였나? · 달리며 든 생각 한 줄 |
| 🎻 바이올린 연습 | 곡 이름 · 오늘 한 것 · 집중한 점 | **오늘 잘 된 것 하나** · 템포(BPM) · 연습한 부분 · 다음에 해볼 것 · **레슨 때 물어볼 것** · 이 곡 지금 어디쯤? |
| 🎓 레슨 | 선생님 피드백 · 다음 레슨까지 과제 | 선생님이 좋다고 한 것 · 새로 배운 것 한 줄 |
| 📚 경제 공부 | 공부 방식 · 분야(여러 개) · 주제 | 한 줄 요약 · 새로 알게 된 용어(`용어 : 뜻`) · 내 생활과 연결 · 아직 헷갈리는 것(체크 목록) · 링크 |
| 📊 투자 | 기록 종류 · 종목 · 관심 이유(여러 개) · 그때 기분 | 근거 세 가지 · 이 판단이 틀린다면? · 확인하고 싶은 점 · 언제 돌아볼까? |
| 🎨 그림 | 종류(모작·창작·연습) · 연습 영역(여러 개) · 주제 | **마음에 드는 곳 하나** · 다음에 해볼 것 · 참고한 강의·영상(+링크) · 원작자 · 새로 시도한 점 · 도구 |

- **예전 칸은 지우지 않았어요.** 컨디션(운동), 어려웠던 점(바이올린·그림), 당시 생각과 근거·나중에 돌아본 결과(투자)는 값이 들어 있으면 **카드에 계속 보이고**, 그런 기록을 수정할 때는 "✍ 더 적기" 안에 "(예전 칸)"으로 나타나요. 새 기록에서는 나타나지 않아요.
- **전에 쓴 값은 최근 쓴 순으로 제안해요**: 곡 이름 · 슬로조깅 장소 · 영상·수업 이름 · 강의 이름 · 원작자 · 투자 종목. (입력 칸을 누르면 목록이 떠요.)
- 운동 기록의 **워치 캡처·클로드 피드백**은 "✍ 더 적기" 안에 있어요. 캡처를 붙여넣으면 자동으로 펼쳐져요.

**칩 선택지 바꾸는 법**: `app.js` 맨 위의 **`CHIPS`** 를 메모장으로 열어 보세요. 따옴표 안의 글자만 고치거나 `'새 칩'`을 쉼표로 이어 붙이면 돼요. 이미 저장한 기록은 그대로 남고, 지워 버린 칩을 골라 둔 기록은 수정할 때 그 칩이 그대로 선택된 채 보여요. (투자 기분 칩은 앞의 그림이 그대로 버튼에 나와요. "3개월 뒤"처럼 **숫자+개월**이 들어 있는 "언제 돌아볼까?" 칩은 그 날짜가 자동으로 계산돼요.)

### 📚 경제 공부 · 📊 투자 화면이 늘었어요
위쪽 칩이 두 줄로 나뉘어요: **경제 공부 메모 · 📒 용어장 · ❓ 헷갈리는 것** / **투자 기록·복기 · ⏰ 돌아볼 때가 된 기록 · 💡 교훈 모음**
- **📒 용어장**: 공부 메모의 "용어 : 뜻"을 모두 모아 **가나다순**(초성 제목)으로 보여줘요. **검색**도 돼요. 같은 용어를 여러 메모에 적었으면 한 항목에 출처가 함께 나와요. 누르면 그 공부 메모로 이동해서 잠깐 표시돼요.
- **❓ 헷갈리는 것**: 체크하지 않은 질문만 모아 보여줘요. 이해했으면 **그 자리에서 체크**하면 목록에서 빠지고, 체크한 것은 공부 메모 카드에서 계속 볼 수 있어요.
- **⏰ 돌아볼 때가 된 기록**: "언제 돌아볼까?"로 정한 날짜가 지난 **복기 전 기록**만 조용한 목록으로 보여줘요. 빨간 알림 줄이나 숫자 표시는 없어요.
- **복기 쓰기**: 투자 카드의 "복기 쓰기"를 누르면 **질문에 답하는 창**이 열려요. ① 근거는 맞았나?(대체로 맞음·반반·빗나감·아직 모름) ② 기분이 판단에 영향을 줬나?(예·아니오·모르겠음) ③ 다음에도 똑같이 할까?(한 줄) ④ **한 줄 교훈**. 그때 적은 근거도 위에 함께 보여줘요. 예전의 "나중에 돌아본 결과" 칸은 그대로 있고, 새 질문은 따로 저장돼요.
- **💡 교훈 모음**: 복기에서 적은 "한 줄 교훈"을 최신순으로 모아요.
- **칩별 개수**: 투자 기록 위쪽에 "관심 이유: 그냥 친숙해서 3번 · …", "그때 기분: 😌 차분 2번 · …"처럼 **개수만** 보여줘요. 평가하는 말은 없어요.
- 투자는 계속 **기록과 복기 전용**이에요. 시세·매매 추천·수익률·계좌 연결은 없어요.

### 🎻 바이올린: 레슨 때 물어볼 것 · 곡 노트
- 연습 기록의 **"레슨 때 물어볼 것"**(한 줄에 하나)은 운동·바이올린 화면 맨 위 **레슨 패널의 "🙋 다음 레슨 때 물어볼 것"**에 모여요. 물어봤으면 체크하면 패널에서 빠져요.
- **레슨 기록을 만들 때**(종류를 "레슨"으로 고르면), 창 맨 위에 아직 안 물어본 것이 나타나요. 거기서도 바로 체크할 수 있어요.
- 레슨 패널의 "N/M 완료 · 모두 끝냈어요" 같은 완료 문구는 뺐어요. 체크는 그대로 할 수 있어요.
- **🎼 곡 노트**: 곡 이름(보라색 밑줄)을 누르면 열려요. **곡 메모 한 줄**(백업에 들어가는 일반 기록으로 저장) · 처음 연습한 날 · 연습한 날 수 · 연습량 분포 · **지금 단계**(가장 최근에 고른 "어디쯤") · **잘 된 것 모아보기**(최신순) · 가장 최근 "다음에 해볼 것" · **템포 그래프** · (예전 칸) 어려웠던 점 모아보기.

### 🎨 그림: 필터 · 📺 강의별 보기
- 그림 기록장 위에 **종류(전체·모작·창작·연습)**와 **연습 영역** 칩 필터가 있어요. 함께 누르면 둘 다 맞는 것만 보여줘요.
- **📺 강의별 보기**: "참고한 강의·영상 이름"이 같은 그림들을 **날짜순으로 나란히** 보여줘요. (앞뒤 공백만 다른 이름은 같은 강의로 봐요.) 그림을 누르면 크게 볼 수 있어요.

### 📖 이번 달 돌아보기에 더해진 것
**이 달 새로 알게 된 경제 용어 · 이 달의 투자 교훈 · 이 달의 "잘 된 것"**(바이올린 잘 된 것 + 그림 마음에 드는 곳) · 연습량 개수 · 운동 종류별 횟수(요가 N · 슬로조깅 N)가 더해졌어요. 곡 이름은 곡 노트로 이어져요. 지난달과의 비교나 퍼센트는 여전히 없어요.

### 🔀 "기능 확장" 프로젝트와 합쳤어요
다른 대화에서 만든 **"나의 기록장 기능 확장"**(PR #1)의 기능을 이 기록장에 모두 합쳤어요.
- **🌙 밤 모드**: 오른쪽 위 🌙 버튼(다시 누르면 ☀️). 고른 것을 기억하고, 고른 적이 없으면 컴퓨터 설정을 따라요. 어두운 화면에서도 모든 글자가 잘 읽히는지 확인했어요.
- **새벽 4시 전에 남긴 기록은 전날 기록**이에요. 밤 11시에 시작해 자정을 넘겨도 그날 기록이 돼요. (`DAY_STARTS_AT`)
- **오늘 탭**: 바이올린 버튼을 누르면 **최근에 연습한 곡 4개가 칩**으로 나와요. 새벽 4시 전에는 어느 날짜로 남기는지 알려줘요. 오늘 남긴 기록이 없을 때도 안내가 나와요. 슬로조깅 칩에는 🏃가 붙어요.
- **캘린더**: 달력 아래에 **범례**(연습량 견본)가 생겼고, 기록이 있는 날은 옅은 보라색에서 연습량에 따라 진해져요.
- 그림의 **종류(모작·창작·연습)와 참고한 것**, 곡 노트의 **곡 메모**도 그쪽과 같은 이름의 칸이라 그대로 이어져요.
- **그쪽에서 만든 기록과 백업 파일도 그대로 열려요.** (연습량이 글자로, 기분이 이모지로 저장된 것도 이 앱의 값으로 읽어요.)
- 저장 방식이 달랐던 것: 그쪽은 오늘 탭에서 연습량 버튼을 누르면 **바로 저장**됐어요. 이 기록장은 연습량·기분·메모를 **고른 뒤 저장**(또는 같은 큰 버튼을 한 번 더)이에요. 메모까지 남기고 싶을 때 편하도록 이쪽 방식으로 두었어요.
- 이름이 달랐던 것: 연습량 버튼 이름이 그쪽은 살짝/적당히/듬뿍이었어요. 이 기록장은 **약간 / 중 / 많이**로 두었어요. 바꾸고 싶으면 `app.js` 맨 위의 `AMOUNTS`에서 `label`만 고치면 돼요. (저장된 값은 숫자라서 이름을 바꿔도 기록은 그대로예요.)

### 🏃 거리(km)와 🎼 템포(BPM)를 다시 넣었어요
이번 요청에 슬로조깅의 거리, 바이올린의 템포, 곡 노트의 템포 그래프가 들어 있어서 다시 넣었어요. 예전에 적어 둔 값도 다시 보여요. 필요 없으면 `app.js` 맨 위 `SCHEMAS`에서 `distance` / `tempo` 줄을 지우면 화면에서 빠져요. (시간(분)은 계속 화면에 없어요.)

## ✨ 이전에 생긴 기능

### 🧩 오늘 탭 · 연습량 · 기분 · 쉼 · 도장 · 돌아보기 · 그때의 나 (1차)

새로 생긴 칸은 **모두 선택**이에요. 안 적어도 저장돼요. 목표·점수·연속 기록·"N일 빠졌어요" 같은 말은 여전히 없어요.

#### ✏️ 맨 앞의 "오늘" 탭 (사이트를 열면 이 탭이 먼저 보여요)
- 🧘 요가 / 🏃 슬로조깅 / 🎻 바이올린 / 🎨 그림 / 📚 경제 공부 **큰 버튼**이 있어요. 하나를 누르면 아래에 작은 창이 열리고, 거기서 **연습량 → 기분 → 한 줄 메모**를 (고르고 싶은 것만) 고르면 돼요.
- **저장** 버튼을 누르거나, **같은 큰 버튼을 한 번 더** 누르거나, 메모 칸에서 **Enter**를 누르면 오늘 날짜의 **"간단 기록"**으로 저장돼요.
- 저장하면 화면 아래에 **✍ 자세히 적기** 버튼이 나와요. 누르면 그 기록의 수정 창이 열려요. (도장·축하를 꺼 두어도 이 버튼은 나와요.)
- 그 아래에 **오늘 남긴 기록**이 작은 칩으로 모여요. 누르면 고칠 수 있어요.
- 예전에는 마지막에 보던 탭이 열렸는데, 이제는 항상 "오늘" 탭이 열려요. 쉼 버튼은 누르면 남기고 **다시 누르면 지워요.**

#### ●●○ 연습량 3단계 (시간 숫자는 적지 않아요)
- **운동 · 바이올린 연습 · 그림 · 경제 공부**에 "연습량" 칸이 생겼어요. **약간 / 중 / 많이** 버튼 중 하나를 누르고, **다시 누르면 풀려요.** (레슨과 투자 기록에는 없어요.)
- 카드에는 **●○○ / ●●○ / ●●●** 로 작게 보여요. ⚡ 빠른 기록 창에도 같은 버튼이 있어요.
- **캘린더**: 기록이 있는 날은 옅은 보라색이고, 그날 남긴 기록 중 가장 높은 연습량에 따라 **조금씩 진해져요.** 달력 아래에 견본(범례)도 있어요.
- **주간 요약**: "연습량: 약간 2 · 중 1 · 많이 0"처럼 개수만 보여줘요. 합계 점수는 없어요.

#### 😊 하고 나서 기분
- **모든 기록**(운동 · 바이올린 연습·레슨 · 경제 공부 · 투자 · 그림)에 "하고 나서 기분" 버튼 3개가 생겼어요. 😊 좋았어요 / 🙂 보통이에요 / 😮‍💨 지쳤어요. 카드 머리줄에 작게 보여요.

#### 😴 쉰 날도 기록
- **오늘 탭**의 "😴 오늘은 쉼" 버튼, 그리고 **캘린더 날짜 창**의 "😴 이 날은 쉼" 버튼을 누르면 쉰 날이 기록돼요. 하루에 하나만 만들어져요.
- 잘못 눌렀다면 다시 누르거나(메모를 적어 둔 쉼은 지우기 전에 물어봐요), 나타나는 **되돌리기**를 누르세요.
- 캘린더에는 색 없이 **😴**만 조용히 나타나고, 주간 요약에는 "쉰 날 N일"만 나와요. 쉰 날도 "기록한 날"에 들어가요.

#### 🎴 도장
- 새 기록을 저장하면 화면 아래에 **랜덤 도장 + 짧은 한 마디**가 잠깐 나타나요. 예) "🎻 오늘도 켰다", "🌙 늦은 밤 수고했어요"
- **밤 10시 이후~새벽 5시 전**에 저장하면 밤 전용 문구에서 골라요.
- 첫 기록이나 "10번째 기록"처럼 딱 떨어지는 숫자에 닿았을 때는 도장 대신 그 축하가 나와요. 기록을 **고칠 때는** 나타나지 않아요.
- 문구는 `app.js` 맨 위의 **`STAMPS`**에서 마음대로 고치거나 더할 수 있어요. 밤 시간은 `NIGHT_START` / `NIGHT_END`예요. **⚙ 백업·설정**에서 끌 수도 있어요.

#### 📖 이번 달 돌아보기
- **📅 캘린더** 아래의 **"📖 이번 달 돌아보기"** 버튼(다른 달을 보고 있으면 "○월 돌아보기")을 누르면 창이 열려요.
- 들어 있는 것: 기록한 날 수(쉰 날 포함) · 종류별 횟수 · 가장 많이 연습한 곡 · 기분 개수 · 첫 그림과 마지막 그림 나란히 · 레슨 피드백 모음. 남긴 것이 없는 항목은 나타나지 않아요.
- 지난달과의 비교, 퍼센트, 목표와의 비교는 없어요. 예시 기록은 세지 않아요.
- 항목은 `app.js`의 **`RECAP_SECTIONS`** 목록에 하나씩 더하는 방식이라, 나중에 경제 용어·투자 교훈 같은 항목을 쉽게 추가할 수 있어요.

#### 🕰 그때의 나
- 오늘 탭 맨 아래에, **한 달 전 → 석 달 전 → 1년 전 오늘**의 기록이 있으면 **한 장만** 보여줘요. (그림 기록이 있으면 그림을 골라 작은 그림으로 보여줘요. 처음 열었을 때 기능을 보여 주려고 예시 기록도 보여줘요.) 없으면 아무것도 나타나지 않아요. 카드를 누르면 그날의 기록 창이 열려요.

#### ⌨️ 키보드 (컴퓨터)
- 입력 창에서 **Cmd+Enter**(Ctrl+Enter도 돼요)로 저장해요.
- **Esc**로 창을 닫아요. 뭔가 적어 둔 창은 닫기 전에 한 번 물어봐요.
- 입력 창이 넓은 화면에 맞게 더 넓어졌어요.

#### 그대로인 것
- 예전 기록과 예전 백업 파일은 그대로 열려요. 백업 파일의 형식은 바뀌지 않았고, 새 칸은 기록에 **더해지기만** 해요.
- 투자 영역은 계속 기록과 복기 전용이에요. 시세·추천·계좌 연결은 없어요.

### ⌚ 워치 캡처 → 클로드 피드백 흐름
**① 워치 캡처 붙이기** (운동 기록)
- 운동 기록에 **워치 캡처** 칸이 생겼어요. 한 기록에 **최대 4장**까지 끌어다 놓거나, 눌러서 고르거나, **Ctrl+V**로 붙여넣을 수 있어요. (휴대폰에서는 앨범에서 고르면 돼요.)
- **🧘 운동·바이올린 화면에 캡처를 바로 끌어다 놓거나 Ctrl+V** 하면, 캡처가 붙은 새 운동 기록 창이 열려요. 날짜는 사진 파일의 날짜로 미리 들어가요. (다르면 고치면 돼요.)
- 카드에는 작은 그림으로 보이고, 누르면 크게 보여요. 큰 사진은 자동으로 줄여서 저장해요.

**② 클로드 피드백 저장** (운동 기록)
- 운동 기록에 **클로드 피드백** 칸이 있어요. 클로드가 해 준 말을 그대로 붙여넣어 두면, 카드의 **💬 클로드 피드백**(눌러서 펼치기)이나 캘린더의 날짜 창에서 나중에 다시 볼 수 있어요.

**③ 클로드에게 보낼 요약 복사**
- 운동·바이올린 화면의 주간 요약 아래 **📋 클로드에게 보낼 요약 복사** 버튼을 누르면, **위에서 고른 주**의 운동·연습·레슨 기록이 글로 정리돼 창에 나타나고 **자동으로 복사**돼요.
- 클로드 대화창에 붙여넣고(Ctrl+V), **워치 캡처는 함께 올리면** 돼요. (캡처는 그림이라 글에 들어가지 않아요.) 창의 글을 고쳐서 **다시 복사**해도 돼요.
- 글 마지막의 부탁 문장은 `app.js` 맨 위의 `CLAUDE_REQUEST`에서 바꿀 수 있어요. 한 기록에 붙일 수 있는 캡처 수는 `SHOT_MAX`예요.

### 🌱 "기록을 잘 남기고 있어요"를 느끼는 기능
점수·목표·연속 기록은 여전히 없어요. 하루 빠져도 끊기는 것이 없고, 쌓인 숫자만 보여줘요. **예시 기록은 세지 않아요.**
- **📅 캘린더 위쪽**: "○월에 기록한 날 · ○○○○년에 기록한 날 · 지금까지 기록한 날"이 며칠인지 보여줘요. 하루에 여러 개를 남겨도 1일이에요. 처음 기록한 뒤 며칠이 지났는지도 알려줘요.
- **🧘 운동·바이올린 위쪽 "지금까지 쌓인 기록"**: 운동 몇 회 · 바이올린 연습한 날 · 연습한 곡 몇 곡 · 레슨 몇 회.
- **🎉 축하 한 줄**: 새 기록을 저장하면 화면 아래에 잠깐 나타나요. 첫 기록이거나 "운동 10번째 기록이에요", "기록한 날이 모두 30일이 되었어요"처럼 딱 떨어지는 숫자에 닿았을 때 나오고, 평소에는 **도장**이 나와요. (위의 🆕 '도장' 참고)

### 🧹 거리(km)와 템포(BPM)를 한 번 없앴다가 다시 넣었어요 (위의 🏃 참고)
- 운동 기록의 **거리(km)** 칸, 바이올린 연습의 **템포(BPM)** 칸과 **템포 그래프**가 없어졌어요. 주간 요약은 **운동 횟수 · 바이올린 연습한 날** 두 가지만 보여줘요.
- 곡 이름은 이제 눌러도 그래프가 열리지 않고 글자로만 보여요.
- 예전에 적어 둔 거리·템포 값은 **화면에서만 숨겨지고** 지워지지 않아요. (수정해서 저장해도 그대로 남고, 백업 파일에도 들어 있어요.)

### 🖼 그림 올리기가 쉬워졌어요
- **그림 기록 추가** 창의 그림 칸이 큰 상자가 되었어요. 사진 파일을 **끌어다 놓거나**, 상자를 **눌러서 고르거나**, 복사·캡처한 그림을 **Ctrl+V로 붙여넣을** 수 있어요. (휴대폰에서는 상자를 누르면 카메라·앨범을 고를 수 있어요.)
- **🎨 그림 기록 화면에 사진을 바로 끌어다 놓으면**, 사진이 붙은 새 그림 기록 창이 열려요. 날짜 칸에는 사진 파일의 날짜가 미리 들어가요. (다르면 고치면 돼요.) 화면에서 Ctrl+V로 붙여넣어도 똑같이 열려요.
- **여러 장을 한꺼번에** 끌어다 놓거나 **🖼 사진 여러 장 올리기** 버튼으로 여러 파일을 고르면, 한 장씩 **"간단 기록"**이 만들어져요. 날짜는 각 파일의 날짜이고, 주제·메모는 나중에 카드의 **수정**에서 채우면 돼요. (이미지가 아닌 파일은 알아서 빼요.)
- 사진을 다른 화면에 잘못 놓아도 브라우저가 사진을 열어 버려서 기록장이 사라지는 일이 없도록 막아 두었어요.
- 큰 사진은 자동으로 줄여서 저장해요. (아이폰 HEIC 사진은 크롬에서 못 열 수 있어요. 사파리에서 열거나 JPG로 바꿔 주세요.)

### 📓 브라우저 탭 아이콘
- 브라우저 탭에 📓 아이콘이 보여요. (별도 이미지 파일 없이 `index.html` 안에 들어 있어요.) 이미 열어 둔 탭에서는 새로고침(F5)하면 바뀌어요.

### ⏱ 시간(분) 칸을 모두 없앴어요
- 운동·바이올린·공부·그림 어디에도 시간(분)을 적는 칸이 없어요. 주간 요약에도 시간은 나오지 않아요.
- 예전에 적어 둔 시간은 **화면에서만 숨겨지고** 지워지지 않아요. (백업 파일에는 그대로 들어 있어요.)

### 📅 캘린더 (새 메뉴)
- 위쪽 메뉴의 **📅 캘린더**에서 한 달 달력으로 기록을 한눈에 볼 수 있어요. **2026년 1월부터** 시작해서 2027년, 2028년… 앞으로도 계속 이어져요. (연도 목록은 앞으로 10년 이상 열려 있어요.)
- 날짜 칸에 그날 한 것이 그림으로 보여요: 🧘 운동 · 🎻 바이올린 연습 · 🎓 레슨 · 📚 경제 공부 · 📊 투자 기록 · 🎨 그림. 같은 종류가 여러 개면 작은 숫자가 붙어요. 컴퓨터 화면에서는 제목도 함께 보여요.
- **날짜를 누르면** 그날 기록이 한 창에 모여 보여요. 거기서 **수정·삭제**, 레슨 과제 **체크**, 그리고 **＋ 버튼으로 그 날짜에 기록 추가**를 할 수 있어요. (지난 날짜에 뒤늦게 적을 때 편해요.)
- 위쪽의 종류 버튼(운동 · 바이올린 · 경제 공부 · 투자 기록 · 그림 · 쉼)을 눌러 보고 싶은 종류만 볼 수도 있어요. **바이올린** 버튼은 연습(🎻)과 레슨(🎓)을 함께 켜고 꺼요. 달력 아래에는 그 달의 기록 개수가 나와요. (목표나 연속 기록 같은 건 일부러 넣지 않았어요.)
- 이 달력은 사이트 안의 달력이에요. 구글 캘린더 같은 외부 서비스와는 연결되지 않아요.

### 💾 자동 저장 (내 컴퓨터의 파일에 저장)
**⚙ 백업·설정 → 자동 저장 켜기**를 누르고 저장할 파일 위치를 **한 번만** 골라 주세요. (예: 문서 폴더의 `나의기록장-자동저장.json`)
- 그 뒤로는 기록을 바꿀 때마다 (1~2초 뒤) 그 파일에 저절로 저장돼요. 백업 파일과 같은 형식이에요.
- 자동 저장이 잘 되는 동안에는 "백업한 지 오래됐어요" 안내가 뜨지 않아요.
- **크롬·엣지(컴퓨터)**에서만 쓸 수 있어요. 사파리·파이어폭스·휴대폰에서는 예전처럼 백업 파일을 가끔 내려받아 주세요.
- 브라우저를 껐다가 다시 열면, 보안 때문에 **위쪽에 "다시 연결"** 안내가 뜰 수 있어요. 누르면 이어서 저장돼요. (멈춰 있는 동안 바꾼 것도 한꺼번에 저장돼요.)

**브라우저 기록을 지운 뒤 되살리는 방법**
- 브라우저에서 "인터넷 사용 기록 삭제"를 할 때 **"캐시된 이미지 및 파일"만** 지우면 기록은 안전해요. 하지만 **"쿠키 및 기타 사이트 데이터"까지 지우면 기록이 사라져요.**
- 그럴 때는 ① `index.html`을 다시 열고 → ② **⚙ 백업·설정 → 백업 파일 불러오기**에서 자동 저장 파일을 고르면 그대로 되살아나요.
  (또는 **자동 저장 켜기**에서 같은 파일을 고르면 "기록이 N개 들어 있어요. 합칠까요?"라고 물어보고 합쳐서 이어가요. 빈 화면이 파일을 덮어쓰지 않아요.)
- 자동 저장 파일은 지우거나 옮기지 말고, 가끔 다른 곳(USB, 클라우드 폴더 등)에 복사해 두면 더 안심이에요.


### 1. 백업 알림
- 마지막으로 **백업 파일을 내려받은 날짜**를 기억해요. **⚙ 백업·설정** 화면에서도 볼 수 있어요.
- 백업한 지 **14일이 지났거나 한 번도 안 했으면**, 화면 위쪽에 빨간 안내 줄이 나타나요.
  예: "마지막 백업 후 16일이 지났어요 [지금 백업] [나중에]"
- **[지금 백업]** 을 누르면 바로 백업 파일이 내려받아지고 안내 줄이 사라져요.
- **[나중에]** 를 누르면 **3일 동안** 안내 줄이 보이지 않아요.
- 기록이 하나도 없을 때는 안내 줄을 띄우지 않아요.
- 몇 일마다 알릴지는 `app.js`의 `BACKUP_REMIND_DAYS`(14), 미루는 기간은 `BACKUP_SNOOZE_DAYS`(3)에서 바꿀 수 있어요.

### 2. 빠른 기록 (⚡ 보라색 버튼)
운동·바이올린 / 경제 공부·투자 / 그림 메뉴마다 **⚡ 빠른 기록** 버튼이 있어요.
날짜(오늘로 미리 채워져 있어요), 종류, 한 줄 메모만 적으면 끝나요.

| 메뉴 | 종류 | 한 줄 메모가 들어가는 곳 |
| --- | --- | --- |
| 운동·바이올린 | 요가 / 슬로조깅 / 바이올린 연습 | 운동은 "메모", 바이올린은 "연습한 부분" |
| 경제 공부·투자 | 공부 메모 / 투자 기록 | 공부는 "주제", 투자는 "관심 자산·종목" |
| 그림 | 연필·드로잉 / 색연필 / 수채·물감 / 디지털 / 기타 | "연습 주제" (종류는 "사용한 도구"로 저장돼요) |

- 빠른 기록으로 만든 카드에는 **보라색 "간단 기록"** 표시가 붙어요.
- 나중에 카드의 **수정** 버튼으로 나머지 칸을 채울 수 있어요. 꼭 써야 하는 칸까지 채워서 저장하면 "간단 기록" 표시가 사라져요.
  (예: 곡 이름 없이 빠르게 남긴 바이올린 연습은 곡 이름을 적을 때까지 표시가 남아 있어요.)
- 휴대폰 화면에서는 버튼과 입력 칸이 손가락으로 누르기 편하게 더 크게 보여요.
- 종류 목록은 `app.js` 맨 위의 `QUICK` 부분에서 바꿀 수 있어요.

### 3. 바이올린 레슨 노트
- **레슨 기록**: 바이올린 기록을 추가할 때 **종류**를 "레슨"으로 고르면 **선생님 피드백**과 **다음 레슨까지 과제** 칸만 나타나요.
  과제는 한 줄에 하나씩 적으면 체크박스 목록이 돼요.
- **과제 확인**: 운동·바이올린 메뉴 **맨 위**에 가장 최근 레슨의 과제가 나와요. 그 자리에서 바로 체크하면 저장돼요.
  (레슨 카드 안에서도 체크할 수 있어요. 수정에서 과제를 더 적어도 이미 체크한 것은 그대로예요.)
- **곡 이름**: 연습 기록의 곡 이름 칸을 누르면 **전에 쓴 곡 이름이 자동완성**으로 나타나요.
- 주간 요약의 "바이올린 연습한 날"은 **연습 기록만** 세고, 레슨은 "레슨 N회"로 따로 보여줘요.

### 예전 기록과 백업 파일은 그대로 써요
- 예전에 만든 기록은 그대로 보여요. 종류 칸이 없던 바이올린 기록은 "연습"으로 취급해요.
- 예전에 받은 백업 파일도 그대로 불러올 수 있어요. 백업 파일 형식은 바뀌지 않았어요.

## 글자(항목 이름, 선택지) 바꾸기

`app.js` 파일을 메모장으로 열면 맨 위에 **"1. 설정"** 이 있어요. 여기서 고칠 수 있어요.

```js
{ key: 'kind', label: '종류', type: 'select', options: ['요가', '슬로조깅'], required: true },
```

- **운동 종류 추가**: `options: ['요가', '슬로조깅', '걷기']` 처럼 따옴표로 감싸 쉼표로 이어 붙이기
- **항목 이름 바꾸기**: `label:` 뒤의 글자만 바꾸기
- 따옴표(`'`)와 쉼표(`,`)는 지우지 마세요. 잘못되면 되돌려 놓으면 돼요.
- 색깔은 `style.css` 맨 위 `:root { ... }` 의 색 값을 바꾸면 돼요.
- 파일을 고친 뒤에는 브라우저에서 새로고침(F5)하면 반영돼요. 기존 기록은 그대로예요.
